#### 2.4 비판적 평가
- **비교 모델(DeepSeek-V3.1 685B/37B, GLM-4.6 357B/32B)에 한국어 일부만 앞선다.** 생각 모드: KMMLU 80.2(76.5 / 79.9), AIME25-ko 86.9(78.1 / 75.9), HRM8K 89.4(84.3 / 83.9), LiveCodeBench-ko 73.1(66.2 / 55.9), IFBench 64.7(41.5 / 43.4). 반면 KoBALT 48.8(59.7 / 59.2), KMMLU-Pro 68.1(71.4 / 71.8), AA-LCR 36.0(53.3 / 54.3), HLE 8.6(13.0 / 13.3), τ² Telecom 58.1(GLM-4.6 70.5), SciCode 32.4(39.1 / 38.4)로 뒤진다. [확인: 읽은 값, 벤더 보고]
- **장문·긴 에이전트 평가가 약하다.** AA-LCR 36.0은 비교 모델의 약 3분의 2다(계산). K2에서 컨텍스트가 두 배(131K에서 262K)가 된 이유로 보인다. [확인 / 추정]
- **비생각 모드는 코딩에서 더 뒤진다.** HumanEval+ 79.9(87.8 / 89.0), MBPP+ 85.7(92.6 / 94.2). [확인: 읽은 값]
- **독립 평가가 없다.** 다른 정리 사이트는 활성 330억·컨텍스트 131K만 옮겨 적는다. [미확인]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: A.X K2와의 세대 비교, 한국어 수학·코드 혼합 평가의 기준선.
- 쓰지 않는다: 새 구축(K2가 모든 한국어 지표에서 앞선다), 장문 작업, 경량 배포.
