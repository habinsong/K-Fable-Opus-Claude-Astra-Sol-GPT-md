## 2. 이 모델의 웹 리서치 작업 운용
A.X K1의 웹 리서치 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- τ² Telecom 58.1(GLM-4.6 70.5, DeepSeek-V3.1 37.4), IFBench 64.7(비교 모델 41.5 / 43.4).
- KMMLU 80.2, CLIcK 84.9, MMLU-Pro 81.5, GPQA-Diamond 74.0, AIME25 89.8, HLE 8.6.

**웹 리서치 작업에서 따로 확인할 것**
- 검색 도구의 인용 정확도, 출처 날조 빈도, 긴 조사에서의 일관성를 같은 과제로 비교 모델과 직접 대조한다. [추정]
