#### 2.1 위치와 사양
- 2026-07-29 공개한 SK텔레콤의 오픈 가중치 플래그십이다(트래커 날짜, 기술 보고서 arXiv 2608.30181은 8월 31일). Apache 2.0. 지원 언어 5개(영어·한국어·중국어·일본어·스페인어), 텍스트 전용(이미지·오디오·비디오 입력 미지원). 정부 사업 2라운드 1위(70.6). [확인: 모델 카드 / 부분: 날짜]
- 총 6,880억(Hub 692B) MoE, 토큰당 활성 330억(활성 비율 약 4.8%, 계산). 61층(밀집 1 + MoE 60), 은닉 7,168, 전문가 256개(활성 8 + 공유 1), 전문가 차원 2,048, 어휘 163,840, 질의당 희소 어텐션 top-k 2,048. [확인]
- 컨텍스트 262,144(128K로 학습한 뒤 YaRN으로 확장). RULER 전체 94.6, 길이별 4K 97.5 → 128K 92.7 → 256K 86.6. 바늘 찾기(NIAH)는 32K·128K·256K와 NVFP4 양자화 뒤에도 100점. [확인]
- 학습: 약 8.2조 토큰(일반 6.4조 + 추론 1.4조 + 장문 0.36조), 1단계 언어 비율 영어 72.7% / 한국어 15.4% / 코드 8.3%, 후학습 SFT 약 606억 토큰과 약 10만 프롬프트 강화 학습. FP8(MXFP8 E4M3)로 네이티브 학습. 권장 샘플링 온도 0.9, top_p 0.95. [확인]
