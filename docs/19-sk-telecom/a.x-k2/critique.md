#### 2.4 비판적 평가
- **한국어 지식·수학은 강하고 에이전트·코딩은 약하다.** AIME26 97.1(DeepSeek V4 Flash 96.7), Apex 45.8(28.1), KMMLU-Pro 80.5(78.8), CLIcK 91.6(Qwen3.5 88.4), τ²-Bench Telecom 98.0이 비교 모델 중 1위다. 반면 Terminal Bench v2.1 36.0(Kimi-K2.6 65.9), BrowseComp(검색 10회 이내) 9.3(GLM-5.1 29.1), τ³-Banking 13.0(DeepSeek V4 Flash 22.9), LiveCodeBench v6 84.0(89.4)이다. [확인: 읽은 값, 벤더 보고]
- **K1 대비 한국어 지표가 크게 올랐다.** KMMLU-Pro 68.1에서 80.5로 +12.4, CLIcK 84.9에서 91.6으로 +6.7(같은 벤치마크, 계산). 총 파라미터는 519B에서 688B(+33%), 컨텍스트는 131K에서 262K로 두 배, 활성은 330억으로 같다. [확인: 두 모델 카드]
- **GDPval 1,031(GLM-5.1 1,257), HLE 27.8(Kimi-K2.6 35.9), GPQA-Diamond 85.6(91.1)로 일반 지식은 중위권이다.** [확인: 읽은 값]
- **독립 평가가 없다.** 모든 수치는 SKT 시험이고 비교 모델 선택도 SKT가 했다. [미확인]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 한국어 지식·수학·장문 검색 정확도가 중요한 서버급 자체 호스팅, Apache 2.0 구축.
- 쓰지 않는다: 코딩 에이전트·웹 검색 에이전트 기본 모델, 개인 장비 로컬 실행(647 GiB).

## 재확인 (2026-11-19, 웹 검색, 사용자·후기 글)
- 독립된 사용자 후기를 찾지 못했다. 검색에 나온 것은 제조사 발표·출시 보도·판매 사이트 정리뿐이다. [확인: 부재]
