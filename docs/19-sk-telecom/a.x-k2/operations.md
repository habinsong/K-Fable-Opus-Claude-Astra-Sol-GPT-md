#### 2.2 API·배포·로컬 실행
- **FP8 가중치 디스크 약 647 GiB.** Transformers는 GPU 메모리 합계 800 GiB 이상(B300 4장 검증)이 필요하다. FP8 실행에는 컴퓨트 능력 8.9 이상(RTX 4090, H100, B200)이 필요하고 그렇지 않으면 BF16으로 풀려 약 1.4 TB가 든다. vLLM은 약 656 GiB를 올리고 275GB급 카드 4장으로 돌렸다. [확인]
- vLLM은 SKT 포크(v0.23.0 기반)가 필요하고 Transformers는 소스 설치(v5.14.1 이후 병합)와 `kernels` 0.15.2 이상 0.16 미만이 필요하다. 카드는 양자화 모델 3개와 llama.cpp·Ollama·LM Studio 사용 가능을 안내한다. [확인]
- 외부 서비스로 보내는 요청에는 개인정보, 영업비밀, 미공개 코드를 포함하지 않는다. (자체 호스팅이면 해당 없음)

#### 2.3 행동 특성과 지침 문서를 쓰는 법
- 카드의 한계 서술: 사실 오류 가능(검증 필요), 텍스트 전용, 사전 학습이 영어 중심(단계별 약 73~90%)이라 중국어·일본어·스페인어 품질은 "덜 검증"됐다, 사회적 편향 정량 평가 없음. [확인]
- 에이전트 성능은 "보통"이라고 카드가 직접 적었다(Terminal Bench·BrowseComp에서 상위 모델에 뒤짐). 에이전트 작업 기본 모델로 가정하지 않는다. [확인]
