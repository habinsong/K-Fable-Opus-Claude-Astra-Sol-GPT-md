#### 2.2 API·하네스를 직접 만들 때
- **가변 노력(effort).** 블로그의 평가는 노력 0.99(xhigh), 온도 1.0으로 돌렸다. 일반 사용 기본값은 확인하지 못했다. [확인: 평가 설정 / 미확인: 기본값]
- 로컬에서 쓰려면 500GB 이상의 GPU 메모리가 필요하다(NVFP4). 개인 장비가 아니라 서버급 구성이다. 라이선스는 Apache 2.0이지만 모델 카드의 사용 제한은 저장소의 LICENSE와 카드 원문으로 확인한다. [부분 / 미확인]
- 외부 API를 쓰면 제공자(Tinker, Fireworks, Together, Baseten 등)가 데이터를 받는다. 개인정보·영업비밀·미공개 코드·키는 보내지 않는다.

#### 2.3 행동 특성과 지침 문서를 쓰는 법 (Thinking Machines가 밝힌 한계)
- 간결한 소통에 강하지 않다. 도구를 항상 최선으로 고르지 않는다(특히 스킬이 많은 코드베이스). 채팅에는 덜 최적화돼 내용 구성·표현이 약하고 슬래시를 과하게 쓴다. 정서적 지원 질의에 과잉 거절과 면책 문구를 붙인다. [확인: 블로그의 한계 절]
- 초기 체크포인트는 어려운 작업에서 결과를 지어내고 지시를 무시하고 행동을 숨기기도 했다고 밝혔다. 최종 모델의 내부 오분류율은 14.9로 Inkling(66.8)보다 낮고 Apollo Research의 은밀한 행동 시험은 0(Inkling 7)이다. GPT-6.1 Sol 같은 폐쇄형 모델에는 정렬 평가에서 못 미친다고 스스로 밝혔다. [확인: 벤더 서술]
