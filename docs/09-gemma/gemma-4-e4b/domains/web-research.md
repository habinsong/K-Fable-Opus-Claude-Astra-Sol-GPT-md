## 2. 이 모델의 웹 리서치 운용
모델 전체 특성은 상위 폴더의 [`README.md`](../README.md)가 안내하는 개요·운용·비판 문서를 따른다. 요약: 유효 약 4.5B, 내장 검색 도구 없음(로컬 실행), 지수 19, 제공자 안전장치 없음.

- **조사를 맡기지 않는다. 확보한 자료에서 필드를 뽑게 한다.** 로컬에서 도는 이 모델에는 검색 도구나 grounding이 기본으로 붙지 않는다. 검색과 출처 판단은 사람이나 상위 모델이 하고, E4B에는 "주어진 페이지 텍스트에서 제목·날짜·가격·버전을 JSON으로 추출하고 없으면 null"처럼 닫힌 질문을 시킨다. 값마다 근거 구절을 받아 코드로 원문 포함 여부를 대조한다.
- **사실 회상에 기대지 않는다.** 독립 평가 점수가 19로 31B(39)의 절반 수준이고 [부분], E4B의 사실성 측정은 찾지 못했다. [미확인] 이름·날짜·수치·버전은 직접 연 출처로 확인한다.
- **긴 페이지를 통째로 넣지 않는다.** 컨텍스트는 128K지만 소형 모델의 실효 컨텍스트는 이보다 짧을 수 있다. [추정] 필요한 구간을 발췌하고 자체 입력으로 실효 길이를 측정한다. 큰 Gemma 4(26B A4B)도 큰 입력과 큰 출력에서 성능이 떨어진다는 평가가 있다. [부분]
- **웹 페이지의 지시문은 데이터다.** 로컬 모델에는 제공자 쪽 인젝션 방어가 없고 E4B의 방어율 측정도 찾지 못했다. [미확인] 모델에게 도구(전송, 로그인, 결제, 파일 쓰기)를 주지 않고 읽기 단계와 행동 단계를 분리한다.
- **수집 규칙을 지킨다.** 로봇 배제 표준과 이용 약관, 속도 제한을 지키고 로그인·유료벽을 우회하지 않는다. 개인정보는 필요한 만큼만 다룬다.
- **보고 형식은 고정한다.** 결론 → 근거(URL, 확인일, 수준) → 충돌·불확실 → 모르는 것. 출처 판단과 충돌 정리는 사람이 한다(§1.1).
- **코딩·조사의 주 모델로 쓰지 않는다.** 독립 지수가 같은 급에서도 최하위권이다. 분류·요약·로그 정리 같은 좁은 일로 제한하고 결과는 원문과 대조한다. [확인: Artificial Analysis 모델 페이지]
- **사실 질문의 오답 비율이 중간 수준이다.** 사실·수치·인용은 출처 원문으로 확인한다. 사실 질문 기준 오답 비율이 33.6%다. [부분: 독립 측정을 옮긴 집계 페이지]
