#### 2.1 위치와 사양
- GPT-6.1 Sol의 후속이다. 2026-11-17에 GPT-6.2 Astra와 함께 나왔다. OpenAI는 Sol을 일상적이고 여러 단계로 이어지는 에이전트 작업을 효율적으로 하는 모델, Astra를 가장 어려운 프로젝트용 모델로 안내한다. API ID는 `gpt-6.2-sol`이다. [확인: 모델 ID·위치 / 부분: 출시일(OpenAI 개발자 커뮤니티 공지, 집계·보도)]
- 모델 페이지에서 직접 읽은 사양: 컨텍스트 1,050,000, 최대 입력 922,000, 최대 출력 128,000, 지식 컷오프 2026-06-01, 입력은 텍스트·이미지, 출력은 텍스트. [확인]
- 가격(100만 토큰, Standard)은 입력 $2 / 캐시 입력 $0.10 / 출력 $10으로 6.1 Sol과 같다. 캐시 쓰기는 30분 보관 $2.50, 12시간 보관 $5(단문 요청). 배치는 Standard의 50%, Fast는 2배, Ultrafast는 2027-02-28까지 3배이고 2027-03-01부터 6배다. 입력이 272K 토큰을 넘으면 요청 **전체**에 입력·캐시 2배, 출력 1.5배가 붙는다. [확인]
- 엔드포인트는 Chat Completions·Responses·Batch이고 Realtime·Assistants·미세조정·예측 출력은 지원하지 않는다. Responses 도구: 웹 검색, 파일 검색, 이미지 생성, 코드 인터프리터, hosted shell, apply patch, skills, 컴퓨터 사용, MCP, 도구 검색. [확인]
- 추론: effort `none`은 거부된다. 가이드는 새 연동을 `medium`으로 시작하라고 한다. 모델 페이지와 가이드는 허용 값 전체와 기본값을 적지 않았다. 독립 평가 사이트가 low·medium·high·xhigh·max를 각각 측정해 단계가 있는 것으로 읽힌다. [확인: 거부·권고 / 부분: 단계 전체 / 미확인: 기본값]
- 6.2 Sol은 Astra와 별개 가격표를 가진다. GPT-6.1 Astra는 확인되지 않았다. 이 저장소의 `gpt-6-astra`는 6 Astra, 6.2 Astra는 `gpt-6.2-astra`다.
- 가용성: ChatGPT Work와 Codex(Plus·Pro·Enterprise·Edu), API. 일반 ChatGPT Chat에는 추가되지 않았다는 직원 메모가 있고 일부 사용자는 출시 직후 모델이 보이지 않는다고 적었다. [부분: 공지 스레드]
