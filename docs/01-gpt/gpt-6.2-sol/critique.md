#### 2.4 비판적 평가 (독립 지표는 직접 읽은 한 사이트, 나머지는 2차)
- **독립 지표: Artificial Analysis 지수 57(`max`, 92개 중 11위).** effort별로 `xhigh` 56(작업당 5.0분), `high` 55(4.3분), `medium` 53(3.1분), `low` 41(1.4분)이고 `max`는 8.0분이다. `max` 기준 출력 속도 85 tok/s, 첫 답 토큰까지 66.7초, 블렌디드 가격 $1.47(100만 토큰). Astra는 같은 지수에서 62로 Sol(`max`)보다 5점 높다. [확인: 페이지에서 읽은 값]
  → 계산하면 `medium`에서 `high`로 올릴 때 +2점에 +1.2분, `high`에서 `max`로 올릴 때 +2점에 +3.7분이 든다. 이득이 시간에 비해 빠르게 줄어든다. 시작은 `medium`, 막히면 `high`가 합리적이다. [추정]
- **벤더 수치.** OpenAI는 FrontierCode 2.0의 병합 가능한 변경에서 Sol이 Astra에 근접하며 비용은 약 5분의 1이라고 한다. 한 보도는 작업당 비용이 약 20% 낮아졌다고 적었다. 원문 표는 이미지라 읽지 못했다. [부분, 벤더 주장]
- **6.1 Sol에서 측정된 결과는 승계되지 않는다.** 6.1 Sol의 보안 통과율(34.1%)과 코딩 기만 평가 같은 측정은 6.2 Sol에 다시 이뤄진 적이 없다. 6.2 Sol도 생성 코드를 기능 테스트와 별도로 보안 검토하고, 테스트를 고쳐 통과시키지 않았는지 `git diff`로 확인한다. [미확인]
- **글쓰기는 나아지지 않았다는 사용자 보고가 있다.** 포럼의 사용자와 중재자가 창작 글쓰기에서 큰 개선이 없고 산문·소설에는 6.1 Terra를 권한다고 적었다. [부분: 포럼]
- **안전장치.** 고위험 사이버 지원에 더 엄격한 보호장치가 적용되고 승인된 방어자에게는 Daybreak를 통해 거부를 줄여 제공할 계획이라고 한다. 보안 업무에서 거부될 수 있다. [부분: 공지 전달]
- **6.1 대비 공식 직접 비교는 없다.** OpenAI는 전문 산출물·코딩·컴퓨터 사용·효율이 나아지고 비용이 낮아졌다고만 말한다. [부분]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 일상적인 구현·수정·리뷰·디버깅의 기본 모델, 반복 루프가 많은 에이전트 작업, 비용에 민감한 장시간 작업.
- 올린다: 같은 문제에서 두 번 이상 막히면 Astra로 올린다. 시작은 `medium`, 어려우면 `high`.
- 쓰지 않는다: 가장 어려운 연구·보안 분석(Astra), 대량·저지연 단순 작업(Luna·Terra), 창작 글쓰기.
