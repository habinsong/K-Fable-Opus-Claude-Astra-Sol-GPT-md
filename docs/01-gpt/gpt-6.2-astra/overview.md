#### 2.1 위치와 사양
- GPT-6.2 시리즈의 최상위다. 2026-11-17에 출시됐다. OpenAI는 "가장 어려운 프로젝트"용 모델이며 자사에서 가장 유능한 사이버 모델이라고 안내한다. API ID는 `gpt-6.2-astra`다. 이 저장소의 `gpt-6-astra`(6 Astra)와는 다른 모델이다. [확인: ID / 부분: 출시일·소개(공지 스레드, 보도)]
- 모델 페이지에서 직접 읽은 사양: 컨텍스트 1,050,000, 최대 입력 922,000, 최대 출력 128,000, 지식 컷오프 2026-05-18, 입력은 텍스트·이미지, 출력은 텍스트. [확인]
- 가격(100만 토큰, Standard 단문)은 입력 $8 / 캐시 입력 $0.40 / 출력 $40이다. 캐시 쓰기는 30분 $10, 12시간 $20. 배치 50%, Fast 2배, Ultrafast는 2027-02-28까지 3배, 2027-03-01부터 6배. 입력이 272K 토큰을 넘으면 요청 전체에 입력·캐시 2배, 출력 1.5배다. 6 Astra($10/$50)보다 입력·출력 모두 20% 낮다. [확인: 6.2 / 부분: 6 Astra 가격은 이 저장소 `gpt-6-astra` 문서]
- 엔드포인트·기능·도구는 6.2 Sol과 같다(Chat Completions·Responses·Batch, 도구 호출은 Responses). effort `none`은 거부되고 허용 값 전체·기본값은 페이지에 없다. 공지는 Astra의 비교에서 `xhigh`를, 6 Astra의 비교에서 `max`를 언급한다. [확인/부분/미확인]
- 안전장치: 고위험 사이버 지원에 더 엄격한 보호장치가 적용되고 승인된 방어자에게는 Daybreak를 통해 거부를 줄여 제공할 계획이라고 한다. [부분: 공지 전달]
- 가용성은 6.2 Sol과 같다. Pro 500 요금제는 두 모델 모두 Ultrafast를 쓸 수 있고 Pro 200은 Sol부터 쓸 수 있다고 한다. [부분: 공지 스레드]
