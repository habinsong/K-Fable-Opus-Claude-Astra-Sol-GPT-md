#### 2.1 위치와 출시
- GLM-5.3 계열의 경량 모델이다. 출시일은 2026-08-26(Z.ai 릴리즈 로그를 인용한 서술과 일부 중개 사이트)과 2026-09-18(한 중개 사이트)로 갈린다. 가중치는 MIT 라이선스로 공개됐다는 서술이 여러 곳에 있다(플래그십은 MIT가 아니다). [부분, 충돌]
- `glm-5.3-flashx`라는 변형도 있다. 문서화된 차이는 서빙 속도뿐이고 파라미터·컨텍스트·입력 방식이 다르다는 근거는 찾지 못했다. 한 스펙 페이지는 Flash가 텍스트와 이미지만 받는다고 적어 영상 입력 서술과 충돌한다. [부분, 충돌]

#### 2.2 사양 (출처마다 다름)
- **MoE, 총 약 320B, 활성 약 18B.** 컨텍스트 최대 100만 토큰, 최대 출력 약 128K 토큰(FlashX 안내에는 131,072, 추론 토큰이 이 한도에 포함됨). 입력은 텍스트·이미지·영상(·파일)이라는 서술이 주류이며, 도구 호출, 구조화 출력, 컨텍스트 캐싱을 지원한다고 한다. 플래그십과 달리 네이티브 멀티모달이라는 서술도 있다. [부분, 충돌]
- **로컬 실행은 소비자 장비 대상이 아니다.** 네이티브 FP8 체크포인트가 가중치만 약 306 GiB라는 안내가 있다(전체 서버 메모리 요건이 아니다). 서빙 도구로 SGLang, vLLM, TokenSpeed, KTransformers가 안내된다. 다중 GPU 서버가 필요하다. 한 개인 시험에서는 Unsloth의 1비트 양자화(약 93 GB 파일)를 llama.cpp로 GPU 5장에 나눠 올려 SVG 생성, 코딩 게임, 윤리 질문을 돌렸고 큰 컨텍스트에서도 프리필 처리량이 초당 1,100~1,500 토큰이었다고 한다. 1비트 양자화의 정확도 손실은 측정되지 않았고 단일 일화다. [부분: 개인 후기]
- **가격은 출처마다 달라 확정할 수 없다.** 입력/출력(100만 토큰당)이 $0.04/$0.08(FlashX로 표기된 한 중개 사이트), $0.15/$0.50(한 집계), $0.20/$0.50(한 중개 사이트)로 다르고 무료 등급(OpenRouter의 `:free` 변형, 요청 한도 있음)도 있다. 무료 등급은 한도가 예고 없이 줄 수 있고 개발 도구(OpenCode)에서 기간 한정 무료로 제공됐다는 안내가 있다(입력 20만·출력 3.2만 토큰 한도, 종료일 미확인, 운영 용도로는 권하지 않음). Z.ai 요금제에서는 이 모델이 플래그십보다 낮은 크레딧 비율로 차감된다. [부분, 충돌]

## 재확인 (2026-11-19, Hugging Face 모델 카드 직접 읽기)
- [zai-org/GLM-5.3-Flash 모델 카드](https://huggingface.co/zai-org/GLM-5.3-Flash): 총 320B(Hub 321B), 활성 18B(활성 비율 약 5.6%, 계산). 희소 어텐션 + 선형 어텐션 하이브리드와 Manifold-Constrained Hyper-Connections(mHC). GLM-5 계열 최초의 네이티브 멀티모달(이미지-텍스트→텍스트). 라이선스 MIT. 텐서 형식 BF16·F8_E4M3·F32. 언어 영어·중국어. 모델 한도로서의 컨텍스트는 카드에 없고 평가 각주에 300K·400K·1M(장문)과 BabyVision 164K가 있다. [확인]
- 벤치마크(Hub 평가 메타데이터): Terminal-Bench 2.1 84.3, DeepSWE 63.4(주석 불명), Agents Last Exam 26.3, ParseBench 평균 70.75(텍스트 내용 88.34, 텍스트 서식 79.49). 비교는 정성("GLM-5.2를 앞선다", "코딩·에이전트에서 Claude Opus 4.8에 근접")뿐이고 숫자가 없다. 같은 지표에서 Xiaomi MiMo-V2.6-Flash는 Terminal Bench 2.1 87.6이다. [확인 / 부분]
- 추론 노력 `low` / `high` / `max`(기본 `max`, 벤치마크 재현은 `max`). `clear_thinking`은 기본 false, 채팅이면 true. 샘플링 온도 1.0, top_p 0.95 또는 1.0. 최대 생성 길이: HLE(도구) 163,840, NL2Repo·Terminal-Bench 65,536. 서빙: SGLang, vLLM, TokenSpeed, Transformers, KTransformers, Unsloth, Docker Model Runner. Hub 양자화 모델 249개, 추론 공급자 13곳. [확인]
- **로컬 현실(2차 정리).** 활성 18B라도 전체 약 320B가 메모리에 올라간다. GGUF 크기는 UD-IQ1_S 86.69 GiB에서 Q8_0 317.56 GiB까지이고 1비트 구성이 128GB 기기에서 돈다고 한다. 소형 PC·DGX Spark에서 약 15~18 tok/s라는 보고가 있다. 메인라인 llama.cpp 지원 여부는 서술이 엇갈린다. [부분 / 충돌]
- 카드에 하드웨어 요구량·한계 절이 없다. Z.ai 모델 카드의 "1M 컨텍스트"를 확인하지 못했다(2차 정리 한 곳만 적음). [미확인]
