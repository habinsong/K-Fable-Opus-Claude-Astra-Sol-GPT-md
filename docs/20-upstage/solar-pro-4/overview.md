#### 2.1 위치와 사양
- Upstage의 에이전트용 플래그십이다. 2026-08-06 출시, 학습 데이터 기준 2026-02, 컨텍스트 512K, 최대 출력 128K. 입출력 언어는 영어·한국어·일본어. 파라미터 수는 비공개다. Upstage 문서가 "Solar Pro 3보다 에이전트 성능이 크게 좋아졌다"고만 하고 점수는 싣지 않았다. [확인: Upstage 콘솔 문서 직접 읽음]
- **가격**(100만 토큰당): 입력 $0.30 / 캐시 입력 $0.06 / 출력 $1.20. 기능: 채팅, 추론 모드, 구조화 출력, 도구 호출. 속도 "빠름", 지능 "높음"이라는 정성 등급만 있다. [확인]
- 제공: Upstage 콘솔·플레이그라운드·온프레미스(문의 양식). API 입력은 학습에 쓰지 않고 수집하지 않는다고 Upstage가 밝혔다. [확인]
