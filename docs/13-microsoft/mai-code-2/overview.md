#### 2.1 위치와 사양
- Microsoft AI의 코딩 전용 모델이다. 2026-11-17 Ignite에서 MAI Code 2 Flash와 함께 공개됐고 GitHub Copilot에서 쓴다. 심층 디버깅, 여러 파일에 걸친 변경, 저장소 전체 추론, UI 개발을 겨냥한다. Microsoft는 "더 어려운 문제에는 아직 조정되지 않았다"고 밝혔다. [부분: InfoWorld 기사(2026-11-18) 직접 읽음]
- **가격**(100만 토큰당, GitHub 가격 페이지 인용): 프로모션(2027-05-17까지) 입력 $0.50 / 캐시 입력 $0.025 / 출력 $2.50, 정가 입력 $1.00 / 캐시 $0.05 / 출력 $5.00. 프로모션은 정가의 50%다(계산). [부분]
- 컨텍스트, 파라미터 수, Azure Foundry 제공 여부는 기사에 없다. 가용성은 GitHub Copilot Pro·Pro+·Max·Business·Enterprise라는 서술과 일부 플랜 제한이 갈린다. OpenRouter·Vercel 같은 외부 경로는 "곧"이다. [부분/미확인]
- Microsoft 모델 카드는 두 모델의 공격적 사이버 능력을 높게 평가한다. 수치는 없다. [부분]
