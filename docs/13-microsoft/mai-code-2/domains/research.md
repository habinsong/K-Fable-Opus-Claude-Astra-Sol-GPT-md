## 2. 이 모델의 연구 작업 운용
MAI Code 2 전용 연구 작업 측정은 찾지 못했다. [미확인] 아래는 이 분야와 관련된 이 모델의 수치와 운용 메모다. 모델 전체 사양은 상위 폴더의 [`overview.md`](../overview.md), 운용은 [`operations.md`](../operations.md)를 따른다.

- 코딩 전용 모델이라 조사·연구 작업의 정확도는 측정되지 않았다. [미확인]
- Microsoft는 어려운 문제에는 아직 조정되지 않았다고 밝혔다.
- 가격·성능 비교는 프로모션 기준이다. 비교 보고서에 프로모션 여부를 명시한다.

**연구 작업에서 따로 확인할 것**
- 논문 인용의 실재 여부, 통계 수치 처리, 가설과 사실의 구분를 같은 과제로 비교 모델과 직접 대조한다. 이 문서의 수치를 연구 작업 성능으로 읽지 않는다. [추정]
- **아주 긴 자율 작업과 기초 과학 연구에는 맡기지 않는다.** 제작사가 이 모델이 그 용도로 조정되지 않았다고 밝혔다. 그런 일은 상위 모델로 하고 이 모델은 다중 파일 변경과 디버깅 범위로 쓴다. [부분: 제작사 발표]
