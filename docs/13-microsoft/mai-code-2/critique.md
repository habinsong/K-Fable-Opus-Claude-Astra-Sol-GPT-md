#### 2.4 비판적 평가 (거의 모두 Microsoft 자체 수치, 독립 평가는 아직 없음)
- **4개 벤치마크 평균(통과율, %):** MAI Code 2 63.2 / GPT-6.1 Sol 64.1 / Claude Opus 5.5 65.3. MAI Code 2가 GPT-6.1 Sol의 98.6%, Opus 5.5의 96.8%다(계산). 항목별: DeepSWE 1.1에서 73.2 / 74.6 / 69.0, Terminal-Bench 2.1에서 84.6 / 85.0 / 78.7, SWE-Atlas에서 43.1 / 47.4 / 57.5, FrontierCode v1.1에서 52.0 / 49.4 / 56.0. SWE-Atlas에서 Opus 5.5와 14.4점 차이로 가장 크게 진다. [부분, 벤더 주장]
- **"Opus 5.5의 96% 성능을 5% 비용으로"라는 요약은 프로모션 가격 기준이다.** 작업당 $0.309 대 $6.306은 4.9%(계산)이지만 정가로는 약 9.8%다. 분석가도 프로모션이 끝나면 격차가 크게 줄어든다고 지적했다. [부분]
- **모델 비용이 전체 개발비에서 차지하는 비중이 작으면 절감 효과가 작다.** 한 분석가는 모델 비용이 개발비의 10%라면 60% 인하가 전체의 약 6% 절감이라고 했다. [부분: 분석가 의견]
- **독립 검증이 없다.** 같은 시기 모델과 같은 조건에서 직접 비교한 외부 평가를 찾지 못했다. 테스트 하네스, 샘플링, 노력(effort) 설정이 비공개다. [미확인]
- **한계 인정.** 어려운 문제에는 조정되지 않았다고 Microsoft가 밝혔다. [확인: 기사 인용]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: GitHub Copilot 안에서 일상 코딩·디버깅의 저가 대안을 비교할 때(프로모션 기간 동안 특히).
- 쓰지 않는다: 가장 어려운 문제(Fable 5.2, Opus 5.5, GPT-6.2 Astra), 코딩이 아닌 작업, 외부 전송이 금지된 코드.
