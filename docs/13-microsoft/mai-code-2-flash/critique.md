#### 2.4 비판적 평가 (거의 모두 Microsoft 자체 수치)
- **3개 벤치마크 평균(통과율, %, 최대 추론):** MAI Code 2 Flash 61.0 / GPT-6 Luna 55.1 / Claude Haiku 5.5 53.9. Luna보다 5.9점, Haiku 5.5보다 7.1점 높다(계산). 항목별: DeepSWE 1.1에서 59.9 / 59.6 / 46.0, Terminal-Bench 2.1에서 78.3 / 69.3 / 73.4, SWE-Atlas에서 44.8 / 36.4 / 42.1. DeepSWE 1.1에서는 Luna와 0.3점 차이라 사실상 같다. [부분, 벤더 주장]
- **작업당 평균 비용 $0.052(프로모션) 대 Luna $0.080, Haiku 5.5 $0.319.** 프로모션이 끝나면 Luna보다 비싸진다(위 계산). 가격 이점은 기간 한정이다. [부분 / 추정]
- **비교 대상이 더 작은 모델들이다.** MAI Code 2 Flash는 Luna·Haiku와 비교됐고 Opus 5.5나 GPT-6.1 Sol과는 비교되지 않았다. 상위 모델 대체를 가정하지 않는다. [확인: 기사]
- **독립 검증이 없다.** 하네스·샘플링·effort가 비공개다. [미확인]
- **AT&T 시험에서 GPT-6.1을 낮은 비용으로 이겼다는 보도가 있으나 독립 확인이 없다.** [부분]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: Copilot 안에서 국소 수정·코드 설명·일상 버그 수정, 프로모션 기간의 대량 저가 처리.
- 쓰지 않는다: 설계·큰 변경·어려운 디버깅, 코딩이 아닌 작업, 프로모션 종료 후의 비용 비교 없이 Luna 대체로 가정하는 경우.
