#### 2.2 API·하네스를 직접 만들 때
- 현재는 GitHub Copilot과 Foundry 제한 미리보기로만 쓴다. 직접 API ID·형식은 확인하지 못했다. [미확인]
- **정가가 되면 비교 우위가 달라진다.** 프로모션 작업당 평균 비용은 $0.052(GPT-6 Luna $0.080, Claude Haiku 5.5 $0.319). 정가는 두 배라 약 $0.104로 Luna의 130%가 된다(계산, Luna 가격 불변 가정). Haiku 5.5의 약 33%는 유지된다. [부분 / 추정]
- 외부 서비스로 가는 요청이다. 개인정보·영업비밀·미공개 코드·키는 보내지 않는다.
