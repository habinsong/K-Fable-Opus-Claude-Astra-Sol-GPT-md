#### 2.4 비판적 평가 (독립 측정·리뷰는 2차 출처)
- **벤더 수치(Anthropic 제품 페이지).** FrontierSWE v2 69.9%(Fable 5.1은 56.3%), OSWorld 2.1 89.3%(83.5%), Remote Labor Index 41.3%(17.9%). 모두 Anthropic 자체 보고이고 독립 확인 전이다. [부분, 벤더 주장]
- **독립 정리(2차).** Artificial Analysis 지수에서 Fable 5.2는 65(`max`), Gemini 4 Carbon은 60(`high`)으로 보도됐다. FrontierCode 2.0은 Fable 5.2 49.1%(`xhigh`, 5.1은 32.4%), Carbon 40.6%. Terminal-Bench 4.0은 Carbon `high` 65.2%가 Fable 61.6%보다 높고 Zapier AutomationBench도 Carbon이 작업당 비용이 낮으면서 근소하게 높다고 한다. 지표·하네스에 따라 순위가 바뀐다. [부분: VentureBeat 보도 등 2차]
- **가격 경쟁 상황.** Carbon의 도입가(입력 $2 / 출력 $10, 2026-11-30까지)는 Fable 5.2의 4분의 1이다. 도입가가 끝나면 $4/$20으로 절반이다. 비용 대비 선택은 직접 비교해 정한다. [부분]
- **안전장치의 거짓 양성.** 사이버·생물 분류기에 걸려 거부되거나 덜 유능한 모델로 라우팅될 수 있다. 가장 높은 사이버 기능은 검증된 조직 전용인 Mythos 5.2에만 있다. 거부된 요청의 표현을 바꾸거나 언어 문서를 주고, 도구 출력의 base64를 컨텍스트에 넣지 않는다(5.1 때의 지침). [확인/추정]
- **쓸 수 있는 곳이 좁다.** 일상 작업에는 과하고 ZDR이 필요한 조직은 쓸 수 없다. [확인]
- **thinking 블록 귀속은 운영 위험이다.** 라우터·대체 모델이 대화를 중간에 다른 모델로 넘기면 추론이 사라지고 prefix 검사 400이 날 수 있다. 직접 요청을 만드는 코드는 배포 전에 시험한다. [확인]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 몇 시간 단위의 대규모 리팩터링·이전, 여러 문서를 가로지르는 조사, Opus 5.5의 `high`·`xhigh`로도 막히는 어려운 문제.
- 쓰지 않는다: 일상적인 구현·리뷰(Opus 5.5나 Sonnet 5.5), 대량·저지연 작업(Haiku 5.5), ZDR이 필요한 업무, 비용에 민감한 반복 루프.
- 시작은 `high`, 반복 작업은 `medium`, 가볍지만 어려운 질문은 `low`도 비교한다.

## 재확인 (2026-11-19, 웹 검색, 사용자·후기 글)
- **비용과 토큰 사용이 가장 큰 불만이다.** 한 비교는 작업당 출력이 Fable 5.2 약 27.4만 토큰, Fable 5.1 약 11.8만, Opus 5.5 약 17.3만이라 적었다. 같은 표에서 Fable 5.2 `high`는 Opus 5.5 `max`보다 약간 높은 점수를 더 낮은 비용으로 낸다. Hacker News 사용자 한 명은 코드 리뷰 하나가 5시간 토큰 예산을 30분 만에 썼다고 했다. API 기본은 `high`, Claude 앱·Claude Code 기본은 `medium`이라는 안내가 있어 비교 시 설정을 맞춘다.
