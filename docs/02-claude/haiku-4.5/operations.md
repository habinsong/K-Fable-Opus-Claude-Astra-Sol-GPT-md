#### 2.3 API·하네스를 직접 만들 때
- 추론을 쓰려면 `thinking: {"type":"enabled","budget_tokens": N}`을 쓴다. effort는 지원하지 않아 추론 깊이는 `budget_tokens`로만 조절한다. [확인]
- **API 버전 `2026-10-21`부터 `temperature`·`top_p`·`top_k`가 모든 모델에서 400이다.** 그 이전 버전에서는 4.5에서 쓸 수 있었다. 새 API 버전으로 올릴 때 4.5 호출 코드에서 이 매개변수를 뺀다. [확인: Anthropic 폐기 매개변수 표]
- **Haiku 5.5로 옮길 때 깨지는 변경**(이 저장소 `haiku-5.5` 문서 §2.2 정리): `budget_tokens` 방식, 샘플링 매개변수, 어시스턴트 프리필, `computer_20250124`가 400이다. 컴퓨터 사용은 `computer_toolset_20260801`을 쓴다. 5.5는 이전 턴의 추론 블록이 컨텍스트에 남는다. [부분: 이 저장소 문서에서 옮김]
- 모델 ID를 별칭(`claude-haiku-4-5`)으로 쓰면 고정 스냅샷으로 풀린다. 재현이 필요하면 스냅샷 ID를 쓴다. [확인]
