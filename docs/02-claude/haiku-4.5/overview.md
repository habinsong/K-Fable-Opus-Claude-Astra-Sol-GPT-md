#### 2.1 위치와 사양
- Claude Haiku 4.5는 Anthropic이 "레거시(Legacy)"로 분류한 Haiku다. 상태는 활성이지만 Haiku 5.5로 옮기라고 안내한다. 2025-10-15 출시. API ID `claude-haiku-4-5-20251001`(고정 스냅샷), 별칭 `claude-haiku-4-5`. [확인]
- **가격**(100만 토큰당): 입력 $1 / 출력 $5. 5분 캐시 쓰기 $1.25, 1시간 $2, 캐시 읽기 $0.10(입력가의 10%), 배치 50% 할인. [확인]
- 컨텍스트 200K, 최대 출력 64K, 입력 텍스트·이미지 / 출력 텍스트. 신뢰할 수 있는 지식 컷오프 2025-02, 학습 데이터 컷오프 2025-07. [확인]
- **추론은 수동 확장 추론**이다. `thinking.type: "enabled"`와 `budget_tokens`를 쓰고 적응형 추론과 effort 매개변수는 지원하지 않는다. [확인]
- **퇴역 일정**: "2026-10-15 이전에는 퇴역하지 않음"으로 약속돼 있고 그 날짜가 이 문서의 기준일(2026-11-19)보다 앞선다. 모델 상태 표는 여전히 활성이고 퇴역 공지는 없다. Anthropic은 공개 모델 퇴역을 최소 60일 전에 통지한다. 한편 Artificial Analysis는 이 모델을 deprecated로 표기한다. 둘이 맞지 않는다. [확인: Anthropic 상태 표·정책 / 확인: 지표 사이트 표기 / 충돌]
- 가용 플랫폼: Claude API, Amazon Bedrock(두 엔드포인트), Google Cloud(Google 관리·Anthropic 관리), Microsoft Foundry, Claude Platform on AWS. [확인]

#### 2.2 같은 계열의 Haiku 위치
- 현재 Haiku는 **Haiku 5.5**(2026-10-07)다. Haiku 5는 모델 목록에 없다. Haiku 3(2026-04-20 퇴역)과 Haiku 3.5(2026-02-19 퇴역), Claude 1·Instant 계열(2024-11-06 퇴역)은 이미 퇴역해 이 저장소의 대상이 아니다. [확인: Anthropic 모델 상태 표]
- 4.5와 5.5의 사양 차이(계산): 입력 단가 $1 대 "$0.10부터"로 단문 기준 10분의 1, 컨텍스트 200K 대 1M으로 5배, 최대 출력 64K 대 128K로 2배. 5.5는 같은 글에서 토큰이 약 30% 더 나오므로(이 저장소 `haiku-5.5` 문서) 같은 글을 처리하는 비용은 약 7.7분의 1이다(0.10×1.3÷1.00, 계산). [확인/부분 / 추정]
