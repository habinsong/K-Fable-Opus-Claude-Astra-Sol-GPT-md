#### 2.2 API·하네스를 직접 만들 때
- 서버급 장비가 필요하다. BF16은 H100 4장, 최적화된 NVFP4는 별도 저장소다. 노트북·개인 PC는 Bolt 계열 대상이다. [확인: 모델 카드]
- 비디오는 1080p면 1 FPS로 최대 128프레임, 720p면 2 FPS로 최대 256프레임을 권장한다. [확인: 모델 카드]
- vLLM 예시 설정: 텐서 병렬 4(GB200은 2), `--gpu-memory-utilization=0.85`, `--max-num-seqs 32`. 컨텍스트 창은 GPU 메모리에 따라 줄어든다. [확인: 모델 카드]
- NVIDIA는 사용 사례별 추가 시험이 필요하다고 모델 카드에 적었다. 모델 카드에 한계 절은 없다. [확인]

#### 2.3 행동 특성과 지침 문서를 쓰는 법
- 이미지·PDF·화면·표 입력에서 수치와 표는 원본과 대조한다. OCRBench v2(영어 68.12 / 중국어 59.15)가 완벽하지 않다는 뜻이다. [확인: 모델 카드 점수 / 추정]
- 한국어: 모델 카드의 언어 목록에 한국어가 명시돼 있지 않다. 다국어 Common Crawl 추출 15개 언어에는 한국어가 포함된다고 한다. 한국어 출력 품질은 직접 시험한다. [확인: 부분 목록 / 미확인: 품질]
