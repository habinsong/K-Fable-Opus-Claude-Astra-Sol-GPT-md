#### 2.4 비판적 평가 (독립 지표는 직접 읽은 한 사이트)
- **독립 지수 43(92개 중 47위, 같은 비교군 중앙값 43).** 같은 사이트에서 읽은 다른 모델은 Fable 5.2 65, Gemini 4 Carbon 60, GPT-6.2 Sol 57, Hydrogen 51(`high`), Muse Wonder 44(`max`)다. 사이트가 모델마다 다른 시점에 읽은 값이라 지수 버전이 같다고 단정하지 못한다. 그래도 플래그십이라는 위치에 비해 중간이다. [확인: 읽은 값 / 추정: 비교]
- **느리다.** 지수 한 작업에 32.3분(중앙값 12.4분), 출력 속도 54 tok/s, 첫 토큰 148.6초. 같은 사이트의 Muse Wonder는 13.3분, GPT-6.2 Sol은 8.0분(`max`)이다. [확인: 읽은 값]
- **벤더 주장은 대부분 내부 지표다.** Code Arena 6위, Agents' Last Exam·Vals Index 등에서 강하다는 서술이 있으나 점수가 보도자료에 없다. 비교 대상은 직전 모델(Qwen3.8-Max)뿐이다. 2차 보도는 Opus 5.5를 일부 시험에서 이겼다고도, 비교가 Fable 5.1이었다고도 적어 서로 맞지 않는다. [부분, 충돌]
- **가중치 비공개.** 이 저장소의 다른 Qwen 모델(`qwen3.8-27b`, `qwen3.8-2.4t-a95b`)과 달리 로컬에서 쓸 수 없다. [확인]
- **이 저장소의 Qwen 계열 평가는 그대로다.** 증류와 벤치마크 최적화 의심, 한국어 출력 품질 변동이 있어 권장하지 않는다.

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 지연이 문제가 안 되는 비동기 장시간 작업에서 값싼 대안을 비교할 때, 이미지·비디오 입력 처리.
- 쓰지 않는다: 지연에 민감한 대화형 작업, 외부 전송이 금지된 코드·데이터, 더 높은 정확도가 필요한 어려운 문제(Fable 5.2·Opus 5.5·GPT-6.2 Sol).
