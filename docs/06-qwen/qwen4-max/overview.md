#### 2.1 위치와 사양
- Alibaba의 플래그십이고 Qwen4 세대의 첫 모델이다. 2026-11-16에 "지금 쓸 수 있다"고 발표했다(Alibaba 보도자료의 날짜). 제한 미리보기(Qwen4-Max-Preview)는 2026-11-11부터 열렸다는 2차 보도가 있다. 접근은 QwenCloud(토큰 플랜·API), QwenWork, QwenStudio다. 정확한 API 모델 ID는 보도자료에 없다. [확인: 출시일·접근 / 부분: 미리보기 날짜 / 미확인: ID]
- 총 2.4조 파라미터의 희소 MoE이고 토큰당 활성 약 710억이다. 활성 비율은 약 3.0%(710÷2,400, 계산)로 같은 세대 Qwen3.8-Max(활성 약 950억, 약 4.0%)보다 낮다. 비전을 기본 지원하고 Artificial Analysis는 입력을 텍스트·이미지·비디오, 출력을 텍스트로 적었다. [확인: Alibaba / 부분: 입력 목록]
- 컨텍스트는 보도자료가 100만 토큰, Artificial Analysis가 984K 토큰으로 적어 서로 다르다. 최대 출력은 어느 쪽에도 없다. [확인/충돌]
- **가격**(100만 토큰당): 입력 $1.50 / 출력 $4.50, 블렌디드 $0.80(캐시 적중:입력:출력 = 7:2:1). Qwen3.8-Max($2/$6, 이 저장소 기록)보다 입력·출력 모두 25% 낮다(계산). 보도자료에는 암묵적 캐시 적중 입력 $0.075만 있다. [확인: Artificial Analysis 읽은 값·캐시 단가 / 부분: 3.8 가격은 2차]
- **가중치는 비공개**다. Alibaba는 플래그십은 비공개로 두고 더 작은 Qwen4 오픈 가중치 모델(Plus·Flash·로컬용 27B)을 나중에 내겠다고 했고 날짜는 없다. [확인: 비공개 / 부분: 소형 모델 구성]
- 사이버: 학습 데이터를 의도별로 걸러 방어 자료(취약점 탐지·수정)는 남기고 공격 자료는 뺐다고 한다. 소프트웨어 엔지니어링 학습에 코드 보안 검사를 넣었다고 한다. [확인: Alibaba 서술, 효과는 미검증]
