#### 2.2 API·하네스를 직접 만들 때
- 정확한 모델 ID와 reasoning 지정 방식은 공식 API 문서로 확인한 뒤 쓴다. 보도자료에는 ID가 없다. Qwen3.8-Max는 `qwen3.8-max`와 스냅샷 `qwen3.8-max-0902`처럼 스냅샷을 구분했으므로 Qwen4-Max도 스냅샷 표기를 확인한다. [미확인]
- 응답 시작이 매우 느리다. Artificial Analysis 측정에서 첫 답 토큰까지 148.6초(같은 비교군 중앙값 12.6초)다. 짧은 상호작용 도구에 직접 연결하면 시간 초과가 날 수 있다. 시간 제한을 넉넉히 두고 스트리밍을 쓴다. [확인: 읽은 값]
- 출력이 길다. 지수 한 번을 도는 데 출력 1.27억 토큰을 썼다(중앙값 6,510만, 약 1.95배, 계산). 가격이 낮아 보여도 작업당 비용은 $3.27로 중앙값보다 낮지 않을 수 있다. 비용 계산은 입력 단가가 아니라 작업당 토큰으로 한다. [확인: 읽은 값 / 추정]
- 외부 서비스(Alibaba Cloud)로 가는 요청이다. 개인정보·영업비밀·미공개 코드·키는 보내지 않는다.

#### 2.3 행동 특성과 지침 문서를 쓰는 법
- Qwen3.8-Max 지침을 기준선으로 쓴다(우회 금지, 단계별 테스트, 필요한 만큼만 추론). Qwen4-Max 전용 행동 연구는 아직 없다. [추정]
- Alibaba는 내부 평가(Work360)에서 3.8-Max 대비 높은 effort 추론에서 토큰 35% 감소, 작업당 비용 약 60% 감소를 주장한다. 독립 측정은 같은 방향의 증거를 주지 않았다(위 출력 토큰). [부분, 벤더 주장]
