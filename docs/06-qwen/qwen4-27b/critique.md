#### 2.4 비판적 평가
- **"곧 나온다"를 뒷받침하는 날짜가 없다.** 이름만 무대에서 나왔고 서면 발표는 학습 중이다. Qwen4-Max도 출시됐지만 가중치는 없다. [확인: 부재]
- **재판매·SEO 사이트가 27B 사양을 사실처럼 적는다.** 곳 수가 독립성을 보증하지 않는다. [부분]
- **Qwen 계열 오픈 모델 라이선스가 갈린다.** Qwen3.8-27B는 Apache 2.0이지만 Qwen3.8-Flash-Next는 qwen-community-1.0이다. Qwen4-27B가 어느 쪽일지 알 수 없다. [확인: 두 모델 카드]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: Qwen 로드맵 추적, 출시 전 대비 체크리스트 작성.
- 쓰지 않는다: 지금 쓸 로컬 모델(Qwen3.8-27B 또는 Qwen3.8-Flash-Next를 쓴다).
