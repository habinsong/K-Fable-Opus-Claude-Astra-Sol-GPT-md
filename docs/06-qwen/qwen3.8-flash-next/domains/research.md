## 2. 이 모델의 연구 작업 운용
Qwen3.8-Flash-Next의 연구 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- GPQA-Diamond 91.7, HLE 35.9, IFBench 81.3, MathVision(CI) 95.7, RealWorldQA 88.5.
- 262,144 → 1M(YaRN). 하이브리드 구조(Gated DeltaNet 3 : 희소 어텐션 1)로 KV 캐시가 작다. LVBench 76.6.

**연구 작업에서 따로 확인할 것**
- 논문 인용의 실재 여부, 통계 수치 처리, 가설과 사실의 구분를 같은 과제로 비교 모델과 직접 대조한다. [추정]
- **사실 질문의 오답 비율이 중간 수준이다.** 사실·수치·인용은 출처 원문으로 확인한다. 사실 질문 기준 오답 비율이 46.8%다. [부분: 독립 측정을 옮긴 집계 페이지]
