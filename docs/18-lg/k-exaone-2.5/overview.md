#### 2.1 위치와 사양
- 2026-11-09 NVIDIA AI Day Seoul 2026(서울 코엑스)에서 API를 무료로 열었다. 개발자·스타트업·기업·연구기관이 docs.exaone.ai에서 API 키를 받아 쓴다. [확인: Korea Times 기사 직접 읽음]
- LG는 "기술 검증 버전"이라고 부른다. K-EXAONE 2.0에 추가 학습을 한 모델이다. 파라미터 수·컨텍스트·라이선스는 기사에 없다. 한 정리 글의 750B는 2.0의 수치를 옮긴 것으로 보인다. [확인 / 미확인]
- LG 내부 분석으로 24개 벤치마크에서 7월 모델 대비 성능이 70% 이상 올랐다고 한다. 기사는 비교 대상 모델을 명시하지 않았다. [부분, 벤더 주장]
- 에이전트 평가(LG가 공개 데이터셋으로 시험): AutomationBench 74.6(DeepSeek V4.1 Flash 74.9, GLM 5.3 `max` 71.6), Claw-Eval 77.3, BrowseComp 78.0, SWE-Bench Pro 59.2. [부분, 벤더 주장]
- LG는 2.5에서 검증한 학습 기법을 3차 모델에 적용해 2027-01까지 프런티어급 EXAONE을 완성하겠다고 했다(공동 대표 임우형). [확인: 기사 인용]

## 재확인 (2026-11-19, 사용자 후기에서 확인한 사양)
- 한 개인 후기([브런치](https://brunch.co.kr/@ainote/236))가 모델 ID `k-exaone_v2.5`, 컨텍스트 최대 524,288 토큰, 추론 노력 `low`·`high`·`max`(기본 `max`), 텍스트 전용, OpenAI 호환 채팅 인터페이스를 적었다. 앞 절의 "컨텍스트 미확인"을 이 서술이 메운다. 이 후기의 약관 서술(비상업 한정, 입출력 학습 사용 가능)은 [`critique.md`](critique.md)에 있다. [부분: 개인 후기]
