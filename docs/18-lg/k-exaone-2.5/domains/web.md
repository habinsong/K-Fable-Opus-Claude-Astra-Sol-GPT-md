## 2. 이 모델의 웹 작업 운용
K-EXAONE 2.5의 웹 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- AutomationBench 74.6(DeepSeek V4.1 Flash 74.9), Claw-Eval 77.3, BrowseComp 78.0(LG 시험).
- SWE-Bench Pro 59.2(LG 시험). 2.0의 SWE-bench Verified 68.2와 다른 지표다.

**웹 작업에서 따로 확인할 것**
- 프런트엔드 과제의 자기 검증 능력, 도구 호출 형식, 반복 작업 단가를 같은 과제로 비교 모델과 직접 대조한다. [추정]
