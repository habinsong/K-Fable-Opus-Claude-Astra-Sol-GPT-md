## 2. 이 모델의 하드웨어 작업 운용
K-EXAONE 2.5의 하드웨어 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- 24개 벤치마크에서 7월 모델 대비 70% 이상 향상(비교 대상 불명, 벤더 주장).
- API 무료 공개. 사양·컨텍스트·가중치는 미공개.

**하드웨어 작업에서 따로 확인할 것**
- 데이터시트·회로도 입력의 정확도, HDL 시뮬레이션 루프, 수치·단위 환각 빈도를 같은 과제로 비교 모델과 직접 대조한다. [추정]
