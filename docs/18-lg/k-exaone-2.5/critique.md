#### 2.4 비판적 평가
- **"70% 향상"은 평균이 아니라 모호한 총괄 수치다.** 같은 시기 비교 가능한 값이 하나 있다. 2.0 모델 카드의 Claw-Eval 77.7이 2.5 기사에서는 77.3으로 오히려 0.4점 낮다. 시험 설정이 달랐을 수 있어 결론은 못 내지만 모든 항목이 오르지는 않았다는 뜻이다. [추정]
- **비교 대상이 중국 오픈 가중치 모델이다.** AutomationBench에서 DeepSeek V4.1 Flash에 0.3점 뒤지고 GLM 5.3(max)을 3.0점 앞선다. 폐쇄형 최상위 모델과의 비교는 없다. [부분]
- **SWE-Bench Pro 59.2는 같은 시기 Qwen3.8-Flash-Next(62.5)·Qwen3.8-27B(61.7)보다 낮다.** 비교 하네스가 다를 수 있다. [부분]
- **독립 평가가 없다.** 수치 전부가 LG 발표다. [미확인]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 국내 서비스에서 무료 API로 에이전트 작업을 시험할 때, 3차 모델 전의 성능 추이를 볼 때.
- 쓰지 않는다: 재현이 필요한 작업, 외부 전송이 금지된 데이터, 가중치가 필요한 로컬 구축(공개 확인 전).

## 재확인 (2026-11-19, 웹 검색, 사용자·후기 글)
- [브런치 후기: LG 엑사원 무료 API, 직접 써 보니](https://brunch.co.kr/@ainote/236): 작성자가 `low` 추론으로 작업 4개를 하룻밤 시험했다. 응답 3.8~7.3초, 3문장 공지·JSON 분류 3건(전부 정답)·세금 신고 시기 질문은 맞았고 보안 설명 쉬운 말로 바꾸기는 내용은 정확했으나 **말투가 반말체로 바뀌었다**. 코딩·환각 시험은 하지 않았다. 표본이 4건이라 품질 결론을 낼 수 없다고 작성자가 적었다. [부분: 개인 후기]
- **추론 토큰 비중이 크다.** 후기의 4개 작업에서 출력 762토큰 중 626토큰(82%)이 추론이었고 모든 작업에서 77% 이상이다. 짧은 요청에도 추론이 붙는다. 같은 후기: 컨텍스트 524,288 토큰, 추론 노력 `low`·`high`·`max`(기본 `max`), 항상 추론 후 답한다. [부분: 개인 후기, 낮은 노력 기준]
- **약관 제약이 크다.** 같은 후기가 읽은 약관: 비상업 목적으로 한정, 고객용 제품에 통합해 제3자가 호출하게 하는 것 금지, 입출력이 기록되어 학습에 쓰일 수 있고 거부해도 이미 학습된 부분은 분리·삭제할 수 없다. 키는 30일 만료, 90일 미사용 시 비활성화될 수 있다. 헤더 기준 일일 100회·분당 60회·초당 1회(문서 예시는 86,400회). 현재 전부 무료. [부분: 개인 후기가 읽은 약관, 원문 미확인]
- 후기가 옮긴 LG 수치(DeepSeek V4.1 Flash, GLM 5.3 비교): Claw-Eval 77.3(75.8 / 77.6), BrowseComp 78.0(75.8 / 79.0), SWE-Bench Pro 59.2(58.4 / 64.0). 격차가 1점 안팎인 항목이 많아 측정 방식이 바뀌면 순위가 바뀐다고 작성자가 지적했다. 본문 §2.1의 AutomationBench 비교 값과 일부 다르다. [부분 / 충돌]
