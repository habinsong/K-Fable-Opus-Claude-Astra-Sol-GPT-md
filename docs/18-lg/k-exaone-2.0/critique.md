#### 2.4 비판적 평가
- **코딩·추론은 비교 모델에 뒤진다.** SWE-bench Verified 68.2(Qwen3.5 76.4, GLM-5.1 73.6, DeepSeek V4 Pro 80.6), Terminal-Bench 2.1 43.8(51.3 / 61.8 / 64.0), HLE 18.3(28.7 / 31.0 / 37.7), GPQA-Diamond 82.2(88.4 / 86.2 / 90.1). 총 파라미터는 GLM-5.1(754B)과 비슷한데 점수는 낮다. [확인: 읽은 값, 벤더 보고]
- **장문 검색과 안전 평가가 강점이다.** OpenAI-MRCR 94.4(Qwen3.5 93.0, DeepSeek V4 Pro 92.9, GLM-5.1 71.5), KGC-Safety 99.8(GLM-5.1 69.3), ROK-Fortress 89.5(DeepSeek V4 Pro 47.6). 한편 AA-LCR 56.2는 비교 모델(62.3~66.3)보다 낮다. 같은 장문 평가라도 지표별로 갈린다. [확인: 읽은 값]
- **한국어 지표도 1위가 아니다.** KMMLU-Pro 69.1(DeepSeek V4 Pro 80.5), Click 84.2(91.6). 한국 모델이라는 이유로 한국어 우위를 가정하지 않는다. 같은 해 A.X K2는 KMMLU-Pro 80.5, Click 91.6이다. [확인: 읽은 값]
- **벤치마크 설정이 카드에 없다.** 상세는 기술 보고서(미열람)를 가리킨다. 독립 평가를 찾지 못했다. [미확인]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 한국어 장문 문서·검색 정확도가 중요한 서버급 자체 호스팅, Apache 2.0이 필요한 국내 구축.
- 쓰지 않는다: 코딩 에이전트 기본 모델(Qwen3.8-Flash-Next 62.5, Qwen3.8-27B 61.7이 SWE-bench Pro에서 더 높고 훨씬 작다), 개인 장비 로컬 실행.
