#### 2.2 API·배포·로컬 실행
- **서버급 장비가 필요하다.** 검증 구성은 H200 8장짜리 노드 2대(GPU 16장), 지연 우선이면 텐서 병렬 16, 처리량 우선이면 텐서 병렬 8 + 데이터 병렬 2다. B200에서는 생성 붕괴를 피하려고 `--disable-prefill-cuda-graph`가 필요하다. 모델 카드에 메모리 수치는 없다. [확인]
- SGLang과 vLLM 모두 LG 포크가 필요하다(추론 파서 `qwen3`, 도구 호출 파서 `qwen3_coder`/`qwen3_xml`). Transformers는 `exaone_moe` 구조로 지원한다. [확인]
- MTP와 DSpark 추측 디코딩으로 약 3~5배 빨라진다고 하나 vLLM은 MTP(4토큰)만 되고 DSpark는 미지원이다. 실제 속도는 환경에 따른다. [확인: 카드 서술, 속도는 벤더 주장]
- 카드는 4개 양자화 모델 링크만 두고 FP8 같은 형식은 명시하지 않는다. 텐서 형식은 F32·BF16이다. [확인]

#### 2.3 행동 특성과 지침 문서를 쓰는 법
- 장시간 에이전트·딥 리서치에는 `preserve_thinking`을 켠다. 켜지 않으면 이전 추론이 버려진다. [확인: 카드 권고]
- 카드의 한계 서술: 부적절하거나 편향된 출력, 의미·구문 오류, 최신이 아닌 지식. 이 저장소의 검증 강제(§1.3)와 같은 방향이다. [확인]
