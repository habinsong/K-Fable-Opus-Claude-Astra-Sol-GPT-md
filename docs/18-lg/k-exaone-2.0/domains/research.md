## 2. 이 모델의 연구 작업 운용
K-EXAONE 2.0의 연구 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- MMLU-Pro 83.5, GPQA-Diamond 82.2, HLE 18.3, AIME 2026 92.3, IMO Answer 78.6, PolyMath 71.3, MMMLU 86.6.
- OpenAI-MRCR 94.4(1위), Ko-LongBench 89.6, AA-LCR 56.2(하위).

**연구 작업에서 따로 확인할 것**
- 논문 인용의 실재 여부, 통계 수치 처리, 가설과 사실의 구분를 같은 과제로 비교 모델과 직접 대조한다. [추정]
- **사실 질문의 오답 비율이 중간 수준이다.** 사실·수치·인용은 출처 원문으로 확인한다. 사실 질문 기준 오답 비율이 30.4%다. [부분: 독립 측정을 옮긴 집계 페이지]
