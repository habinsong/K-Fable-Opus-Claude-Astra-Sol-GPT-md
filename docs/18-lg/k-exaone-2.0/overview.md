#### 2.1 위치와 사양
- 2026-07-31 공개(LG 보도·2차 다수)한 LG의 오픈 가중치 플래그십이다. 기술 보고서 arXiv 2608.04505(8월 5일). 라이선스 Apache 2.0, 지원 언어 10개(한국어·영어·스페인어·독일어·일본어·베트남어·프랑스어·이탈리아어·폴란드어·포르투갈어, 1세대는 6개). 학습 데이터 기준 2025년 2분기. [확인: 모델 카드 / 부분: 날짜]
- 총 7,500억(Hub 표기 749B) MoE, 토큰당 활성 370억(활성 비율 약 4.9%, 계산). 78개 본 층(밀집 2 + MoE 76)과 MTP 1층, 은닉 6,144, 전문가 256개(활성 8 + 공유 1), 전문가 차원 2,048, 어휘 153,600. 어텐션은 128토큰 슬라이딩 윈도우 3층마다 전역 1층 구조이고 64 질의 / 8 KV 헤드. K-EXAONE(236B/23B, 2025-12-31)을 3배 넘게 업사이클했다. [확인]
- 컨텍스트 262,144 토큰. 권장 샘플링은 온도 1.0, top_p 0.95, 추론은 `enable_thinking`(기본 켜짐), 장시간 에이전트 작업에는 `preserve_thinking=True`를 권한다. [확인]
- LG 보고: 24개 벤치마크·9개 범주 평균 70.1(1세대 63.3). 장문 평가(OpenAI-MRCR, AA-LCR, Ko-LongBench) 평균이 GLM-5.1보다 10% 넘게 높다고 한다. 정부 사업 2라운드 점수 69.0(3위, SKT 70.6·Upstage 69.9). [부분, 벤더 주장]
