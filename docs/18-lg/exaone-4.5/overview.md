#### 2.1 위치와 사양
- 2026-04-09 공개한 LG 최초의 오픈 가중치 비전-언어 모델이다. 기술 보고서 arXiv 2604.08644. 입력 이미지+텍스트, 출력 텍스트. [확인: GitHub README 직접 읽음]
- 33B 밀집(Dense) 모델이고 그중 비전 인코더가 1.2B다. 컨텍스트 256K(서빙 예시 262,144). 추론은 `enable_thinking`(기본 켜짐). [확인]
- **라이선스는 EXAONE AI Model License Agreement 1.2 - NC(비상업)다.** 같은 시기 오픈 모델 대부분이 Apache 2.0·MIT인 것과 다르다. [확인]
- 같은 세대: EXAONE 4.0(32B·1.2B, 2025-07-15), K-EXAONE(236B MoE/23B 활성, 2025-12-31), EXAONE Deep(2.4B·7.8B·32B, 2025-03-18), EXAONE 3.5(2024-12-09), 3.0(7.8B, 2024-08-07). [확인]
