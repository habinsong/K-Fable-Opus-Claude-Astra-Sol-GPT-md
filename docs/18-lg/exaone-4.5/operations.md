#### 2.2 API·배포·로컬 실행
- 256K 컨텍스트에 H200 1장 또는 A100-40GB 4장(텐서 병렬)이 필요하다고 안내한다. llama.cpp는 Q4_K_M GGUF와 별도 `mmproj`(BF16) 파일을 쓰고 빌드 b9453 이상이 필요하다. Transformers 5.8.0 이상. SGLang은 LG 포크(`lkm2835/sglang`). [확인]
- vLLM은 `--max-model-len 262144`, 이미지 프롬프트당 64개 제한, MTP 추측 디코딩 3토큰 예시를 준다. TensorRT-LLM은 출시 당일 지원이다. [확인]
- 권장 샘플링: 일반 온도 1.0 / top_p 0.95 / presence_penalty 1.5, OCR·문서·한국어 입력은 온도 0.6 / top_p 0.95 / top_k 20 / presence_penalty 1.5, 텍스트 전용은 온도 1.0 / top_p 0.95. [확인]

#### 2.3 행동 특성과 지침 문서를 쓰는 법
- OCR·문서·한국어 입력에서는 온도를 0.6으로 낮춘다. 카드가 이 입력에 별도 설정을 둔 것은 기본 온도 1.0에서 흔들린다는 뜻이다. [추정]
- 카드의 한계 서술: 부적절하거나 편향된 출력, 의미·구문 오류, 최신이 아닌 지식. [확인]
