#### 2.1 확인된 것과 확인되지 않은 것
- **Google은 발표하지 않았다.** 2026-11-19까지 Google의 공식 모델 목록, 가격 페이지, 발표문에서 Gemini 4 Neon을 찾지 못했다. 이 폴더는 코드와 요금표에서 관찰된 흔적과 보도만 기록한다. [미확인]
- **관찰된 흔적 (모두 2차 전언).** (1) 2026-11-16 Gemini 웹 앱 코드의 업셀 구간에 `gemini-4-neon` 문자열이 있었다고 한다. 유료 구독이 필요한 모델일 것이라는 해석이 붙었다. (2) 2026-11-18 Google Cloud 요금(SKU) 카탈로그에 Gemini API 항목으로 텍스트·이미지·비디오·오디오 SKU가 올라왔고 텍스트가 입력 $3 / 출력 $15, 캐시 입력 $0.15(100만 토큰당)라는 보도가 있다. 같은 날 공개 SKU 카탈로그에서 Neon을 찾지 못했다는 보도도 있어 서로 맞지 않는다. (3) Antigravity CLI 1.5.11에 `gemini-pro-orchestrator-neon` 변형이 추가됐다는 X 게시글 전언이 있다. 이 빌드에서 계획은 Carbon, 실행은 Hydrogen이 맡는다고 한다. [부분/미확인]
- **플래그십이라는 근거는 아직 없다.** 위 흔적이 가리키는 등급은 "Pro 오케스트레이터"와 $3/$15라는 가격뿐이다. 이는 Hydrogen($1.50/$7.50)보다 비싸고 Carbon의 인상 후 가격($4/$20)보다 싸다. Google 발표 기준 현재 최상위 모델은 Carbon이다. Neon이 Carbon을 넘는 최상위 모델이라는 서술은 확인되지 않았다. [미확인]
- **그래서 스펙을 쓰지 않는다.** 모델 ID, 가격, 컨텍스트, `thinking_level` 범위, 도구 지원, 안전 범주, 데이터 처리, 출시일은 모두 [미확인]이다. 이 폴더의 어떤 문장도 Neon의 성능이나 동작을 단정하지 않는다.
- 출시 전에 모델 ID 문자열을 코드에 박지 않는다. 공식 Gemini API 모델 목록에서 확인한 ID만 쓴다.

## 재확인 (2026-11-19, 사용자 전달과 보도)
- 사용자가 Gemini 4 Neon의 가격을 **입력 $3 / 출력 $15(100만 토큰당)**라고 전했다. TestingCatalog(2026-11-18 보도)가 Google Cloud 요금 카탈로그에서 본 항목과 같다: 텍스트 입력 $3 / 출력 $15 / 캐시 입력 $0.15, 이미지·비디오·오디오 SKU 별도, 배치·플렉스는 절반 가격이라는 트윗이 있고 Vertex에는 아직 없다. 같은 날 공개 카탈로그에서 Neon을 찾지 못했다는 보도도 있어 서로 맞지 않는다. [부분: 사용자 전달 + 2차 보도 / 충돌]
- 가격 구도(계산): Hydrogen($1.50 / $7.50)의 정확히 2배, Carbon 인상 후($4 / $20)의 75%, Fable 5.2($8 / $40)의 37.5%. 캐시 입력 $0.15는 입력가의 5%다. 플래그십이라는 근거는 이 가격으로는 설명되지 않는다. [확인: 계산 / 추정]
- 여전히 Google 공식 발표는 없고 모델 ID·컨텍스트·출시일은 [미확인]이다. [미확인]
