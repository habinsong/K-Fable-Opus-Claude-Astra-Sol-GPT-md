#### 2.1 확인된 것과 확인되지 않은 것
- **Google은 발표하지 않았다.** 2026-11-19까지 Google의 공식 모델 목록, Gemini API, OpenRouter에서 `gemini-4-krypton` 항목을 찾지 못했다. [미확인]
- **소문의 내용.** 이름은 2026-11-08~09경 유출자가 내부 체크포인트로 지칭하며 퍼졌고, 초기 시험에서 Carbon보다 낫다는 주장이 있다. 공개된 과제·점수·재현 자료는 없다. Arena에서 시험됐다는 주장은 이름을 붙인 사람 스스로도 의심한다는 보도가 있다. [부분/미확인]
- **판매·집계 사이트의 사양은 믿지 않는다.** 일부 API 재판매 사이트가 컨텍스트 105만 토큰 같은 사양과 가격을 사실처럼 적지만 Google이 확인한 값이 아니다. [미확인]
- **그래서 스펙을 쓰지 않는다.** 모델 ID, 가격, 컨텍스트, 등급, 도구 지원, 출시일은 모두 [미확인]이다. 이 폴더의 어떤 문장도 Krypton의 성능이나 동작을 단정하지 않는다.
- 출시 전에 모델 ID 문자열을 코드에 박지 않는다. 공식 Gemini API 모델 목록에서 확인한 ID만 쓴다.
