#### 2.1 확인된 것과 확인되지 않은 것
- **Google은 발표하지 않았다.** 2026-11-19까지 Google의 공식 모델 목록과 발표문에서 Gemini 4 Oxygen을 찾지 못했다. 이름은 Hydrogen(2026-11-12 출시) 직후 유출 보도에서 나왔다. [미확인]
- **소문의 내용.** 유출 보도는 Oxygen을 Hydrogen보다 위의 Flash급 후속 모델로 서술한다. 속도와 낮은 비용을 겨냥한다는 것이다. 일부 사용자는 Arena에서 `gemini-4-hydrogen` 이름으로 시험된 출력이 Oxygen이라고 주장하지만 Google은 확인하지 않았다. 원소 이름을 쓰는 Gemini 4 계열 명명(Hydrogen, Argon, Carbon)에서 추측한 이름일 수 있다. [부분/미확인]
- **그래서 스펙을 쓰지 않는다.** 모델 ID, 가격, 컨텍스트, 등급, 도구 지원, 출시일은 모두 [미확인]이다. 이 폴더의 어떤 문장도 Oxygen의 성능이나 동작을 단정하지 않는다.
- 출시 전에 모델 ID 문자열을 코드에 박지 않는다. 공식 Gemini API 모델 목록에서 확인한 ID만 쓴다.
