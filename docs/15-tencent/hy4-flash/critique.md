#### 2.4 비판적 평가 (거의 모두 벤더 수치)
- **숫자 벤치마크가 공개되지 않았다.** 보도자료는 Hy4 Preview보다 "약간 낫다"고만 하고 점수가 없다. 독립 평가를 찾지 못했다. Artificial Analysis 페이지는 열리지 않았다(404). [확인: 부재]
- **내부 사용자 85명의 만족도 평가는 근거가 약하다.** 비교 대상이 Haiku 5.5 하나이고 점수가 없으며 Tencent 제품 사용자가 대상이다. [부분]
- **가격이 가장 큰 장점이다.** 같은 시기 모델과 입력 단가 비교: MAI Code 2 Flash(프로모션 $0.05, 정가 $0.10), Muse Ember($0.10), Hy4 Flash($0.07). 출력 단가는 Hy4 Flash $0.281이 MAI Code 2 Flash(프로모션 $0.25) 및 Ember($0.50)와 같은 수준이다. 단가만으로 모델을 고르지 않는다. [확인: 읽은 값 / 추정]
- **무료·할인 기간이 짧다.** WorkBuddy 무료는 2026-11-30까지다. [확인]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: Tencent 생태계 안의 일상 업무 자동화, 대량 저가 처리.
- 쓰지 않는다: 어려운 코딩·수학(Hy4 또는 다른 계열 상위 모델), 외부 전송이 금지된 데이터. 가중치 공개 전에는 로컬에서 쓸 수 없다.
