#### 2.2 API·하네스를 직접 만들 때
- Hy4와 같은 TokenHub API 형식을 따를 가능성이 높지만 Flash의 문서를 읽지 못했다. 모델 ID·형식은 공식 문서로 확인한다. [미확인]
- 요청이 몰리는 시간대 가격과 평시 가격이 다를 수 있다. Tencent의 비용 비교(WorkIndex)는 DeepSeek-V4.1-Flash-1017의 최대 등급 피크 요금 기준이다. [확인: 보도자료 서술]
- 외부 서비스(Tencent Cloud)로 가는 요청이다. 개인정보·영업비밀·미공개 코드·키는 보내지 않는다.

#### 2.3 행동 특성과 지침 문서를 쓰는 법
- 단가만 낮은 것이 아니라 작업당 출력 토큰도 50% 줄었다고 한다(강화 학습 효과, 벤더 주장). 그래서 작업당 비용이 Hy4의 20분의 1, 미리보기의 13분의 1, DeepSeek-V4.1-Flash의 8분의 1이라고 한다. 토큰 단가 차이(9~12배)보다 작업당 격차(20배)가 큰 부분은 더 짧은 출력과 적은 단계에서 나온다. [부분, 벤더 주장]
- 슬라이드 편집 시험에서 Flash 74.0 대 Hy4 78.9로 Hy4보다 낮다. 만족도는 Claude Haiku 5.5에 "근접"했다(내부 사용자 85명, 259과제, 27분류, 점수 없음). [부분, 벤더 주장]
