#### 2.1 위치와 사양
- Tencent Hunyuan 최초의 Flash급 모델이다. 발표일은 2026-11-16이라는 보도가 다수이고 보도자료의 도시·날짜 표기는 2026-11-17(선전)이다. 일상 업무용이고 장시간 소프트웨어 엔지니어링 같은 무거운 작업은 Hy4를 쓰라고 안내한다. [확인: 보도자료 읽음 / 부분: 날짜 충돌]
- 총 2,240억 파라미터(Engram 메모리 640억 포함), 토큰당 활성 120억(활성 비율 약 5.4%, 계산), 컨텍스트 최대 1M, 멀티모달 입력. 디코딩 속도는 150 tok/s 초과로 Tencent가 주장한다. KV 캐시는 Hy3의 24분의 1, Hy4의 6분의 1이다. [확인: 보도자료]
- **가격**: 입력 약 $0.070 / 출력 $0.281 / 캐시 입력 $0.003(100만 토큰당)이고 RMB로는 입력 0.5 / 출력 2 / 캐시 0.02다(두 값이 환율 약 7.1과 맞는다, 계산). Hy4(RMB 6/18) 대비 입력 12분의 1, 출력 9분의 1(계산). 2026-11-30까지 WorkBuddy 무료, TokenHub 50% 할인. [확인: 보도자료(USD) / 부분: RMB]
- 접근: Tencent Cloud TokenHub, WorkBuddy, 元宝, WeCom, QQ, ima, Marvis. OpenRouter는 "곧"이다. [확인]
- **가중치**: 오픈소스화할 계획이지만 날짜·라이선스가 없다. 한 정리는 2026-11-18까지 Hugging Face 모델 카드가 올라왔다고 적었으나 확인되지 않았다. [확인: 계획 / 미확인: 공개]
