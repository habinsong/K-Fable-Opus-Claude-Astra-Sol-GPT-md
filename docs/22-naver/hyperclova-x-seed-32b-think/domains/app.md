## 2. 이 모델의 앱 작업 운용
HyperCLOVA X SEED 32B Think의 앱 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- 코딩 점수 없음. 컨텍스트 128K, 도구 사용·에이전트 평가(Tau²) 항목만 이름이 있다.
- 32B 밀집 BF16, 다운로드 약 60GB, A100 80GB 4장 또는 3장(서술 모순). 대기업·경쟁사 제한 라이선스.

**앱 작업에서 따로 확인할 것**
- 모바일·데스크톱 빌드·서명 도구와의 호환, 긴 세션의 비용, 화면 입력 이해를 같은 과제로 비교 모델과 직접 대조한다. [추정]
