#### 2.1 위치와 사양
- Xiaomi가 오픈 가중치로 낸 MoE다. Hugging Face 게시 2026-09-21 15:39 UTC(일부 보도 09-22). 라이선스 MIT(매출 상한 없음). 형제 모델 MiMo-V2.6-Pro는 총 1.02조 / 활성 420억이다. [확인: 정리 글이 읽은 모델 카드 / 부분: Hugging Face 직접 열람은 401]
- 총 3,090억, 토큰당 활성 150억(활성 비율 약 4.9%, 계산). 48층 중 39층이 슬라이딩 윈도우(128토큰)이고 9층이 전역 어텐션, 은닉 4,096, 라우팅 전문가 256개(활성 8), 공유 전문가 없음. 컨텍스트 1M. 입력은 텍스트·이미지·비디오·오디오. 비전 인코더 6.81억(28층), 오디오 토크나이저 3.08억, 오디오 패치 인코더 1.27억. 추측 디코딩 초안은 설정에 `num_nextn_predict_layers` 3이다. [확인: 정리 글]
- FP8(e4m3) 가중치 172.9 GB(65개 샤드). 권장 서빙은 SGLang 텐서 병렬 16 + 데이터 병렬 2 또는 vLLM 텐서 병렬 8. 샘플링 온도 1.0 / top_p 0.95. Hub 저장소의 Safetensors 표기는 159B로 어느 수치와도 맞지 않는다. [확인 / 충돌]
- Xiaomi가 게시한 토큰 단가는 없다. 정리 글은 V2.5의 해외 입력가가 100만 토큰당 약 $0.10이었다는 보도를 인용하고 비교 위젯은 $0.14로 적었으나 근거가 불명이다. [미확인]
