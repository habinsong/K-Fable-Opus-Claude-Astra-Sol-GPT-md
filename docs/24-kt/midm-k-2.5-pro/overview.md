#### 2.1 위치와 사양
- KT의 32B 플래그십 LLM이다. 2026-02-26 공개(트래커), 기술 보고서 arXiv 2603.18788(2026-03-19 제출, 03-24 수정). **비공개**이고 이전 Mi:dm 2.0 Base·Mini는 MIT 오픈이었다. 논문은 CC BY-NC-SA 4.0. 정부 사업에는 2025년에 신청했으나 선정되지 않았다. [확인: 논문 / 부분: 날짜·비공개 서술]
- Mi:dm 2.0 Base 대비 약 3배 규모로 레이어 예측기 기반 깊이 확장(DuS)으로 만들었다. 컨텍스트를 4,096 → 32,768 → 65,536 → 131,072(128K)로 단계 확장했다. 지속 사전 학습 1단계 데이터 구성은 영어 29% / 한국어 17% / STEM 50% / 다국어 9%. 층 수·은닉 크기·학습 토큰 수는 읽은 범위에 없다. [확인: 논문 일부]
- 후학습: 추론 SFT, 모델 병합, 비동기 강화 학습, 대화 유창성·응답 스타일·도구 사용을 위한 "퓨전 트레이닝". 난이도 인식 강화 학습에서 수학 데이터 전체의 20.1%만 써서 성능을 유지·향상했고 AIME 2024 +20.0%, AIME 2025 +28.6%라고 한다. [확인: 논문 일부]
