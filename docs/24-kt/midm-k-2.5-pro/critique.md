#### 2.4 비판적 평가
- **깊이 확장의 이득은 논문 표로 확인된다.** 확장 직후 비교(평균 점수 기준): 기준선 MMLU 0.772, KMMLU 0.521, GSM8K 0.804, MBPP 0.646 대비 레이어 예측기 방식 0.804 / 0.572 / 0.805 / 0.648. 무작위 층 복제는 GSM8K 0.667로 떨어진다. 한국어 KMMLU +5.1점이 가장 크다(계산). [확인: 논문 표 5]
- **장문 확장은 4K 학습만으로는 실패한다.** 2단계(4K) RULER 평균 42.32이고 16K·32K 열은 0.10 / 0.00이다. 128K 학습 200스텝 뒤 RULER 4K 91.95 → 32K 83.43, 평균 88.79. [확인: 논문 표 7]
- **강화 학습 효과가 확인된다.** AIME25 65.33(SFT)에서 70.67(RL)로 +5.3. 최종 추론 평가 AIME25 70.67, MATH500 90.60, LiveCodeBench 90.85, HumanEval+ 78.00, MMLU-Pro 65.56. 같은 시기 A.X K2(AIME26 97.1)·Solar Open 2(95.7)보다 AIME가 크게 낮다. 시험 연도가 달라(25 대 26) 직접 비교는 아니다. [확인 / 추정]
- **비공개라 재현·자체 호스팅이 불가능하다.** 같은 해 LG·SKT·Upstage·Motif·Kakao가 가중치를 공개했다. [확인]

#### 2.5 쓸 때와 쓰지 않을 때
