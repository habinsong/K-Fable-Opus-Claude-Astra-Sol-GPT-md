#### 2.4 비판적 평가
- **Terminal-Bench 2.1은 비교 6개 모델 중 사실상 최상위다.** 74.9는 Qwen-3.7 max(75.0)에 0.1점 뒤질 뿐 GLM-5.1(61.8)·DeepSeek-V4-Pro(64.0)·Kimi-K2.6(65.9)·MiniMax-3(65.2)보다 높다. τ³-Banking 35.3은 1위(DeepSeek-V4-Pro 30.1)이고 ITBench 51.5(공개 데이터만)도 1위다. [확인: 읽은 값, 벤더 보고]
- **지식·과학은 뒤진다.** GPQA-Diamond 83.4(MiniMax-3 92.9, Qwen-3.7 max 92.4), SciCode 40.6(Kimi-K2.6·Qwen-3.7 max 53.5), CritPt 6.6(DeepSeek-V4-Pro 12.9), OmniScience 정확도 30.1(42.9). 환각 비율은 낮아 "비환각" 71.6이다. [확인: 읽은 값]
- **SWE-Bench Verified 76.2는 Qwen-3.7 max(80.4)에 4.2점 뒤진다.** [확인: 읽은 값]
- **Artificial Analysis 점수가 한 정리에서 11.9와 47로 서로 다르게 적혀 있다.** 어느 쪽이 맞는지 확인하지 못했다. 정부 사업에서 탈락한 것은 사실이다. [충돌 / 확인]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 에이전트·도구 호출·터미널 작업을 서버급 자체 호스팅으로 돌리고 MIT가 필요할 때.
- 쓰지 않는다: 과학·지식 질의 기본 모델, 개인 장비 로컬 실행.
