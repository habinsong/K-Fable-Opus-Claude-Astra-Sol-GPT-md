## 2. 이 모델의 웹 리서치 작업 운용
Motif 3의 웹 리서치 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- τ³-Banking 35.3(1위), τ²-Bench Telecom 94.7(GLM-5.1 97.7), ITBench 51.5(1위), GDPVal v2 38.7.
- GPQA-Diamond 83.4(92.9), HLE 37.0, IMOAnswerBench 83.2, CritPt 6.6, OmniScience 정확도 30.1 / 비환각 71.6.

**웹 리서치 작업에서 따로 확인할 것**
- 검색 도구의 인용 정확도, 출처 날조 빈도, 긴 조사에서의 일관성를 같은 과제로 비교 모델과 직접 대조한다. [추정]
- **출력 토큰이 많이 든다.** 지수 평가에서 같은 급 중앙값보다 훨씬 많은 출력을 만들었다. 토큰 예산을 넉넉히 잡는다. [부분]
