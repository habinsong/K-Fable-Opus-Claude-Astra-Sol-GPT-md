## 2. 이 모델의 네이티브 작업 운용
Motif 3의 네이티브 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- SWE-Bench Verified 76.2(Qwen-3.7 max 80.4), Terminal-Bench 2.1 74.9(비교 최상위권), SciCode 40.6(53.5).
- 총 314B, 262,144 컨텍스트, vLLM Motif 포크, NVFP4 체크포인트 별도. MIT.

**네이티브 작업에서 따로 확인할 것**
- 메모리 안전·동시성 버그 진단 정확도, 디버거·새니타이저 출력의 해석를 같은 과제로 비교 모델과 직접 대조한다. [추정]
