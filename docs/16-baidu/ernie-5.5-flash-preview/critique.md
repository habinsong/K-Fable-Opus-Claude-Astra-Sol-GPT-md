#### 2.4 비판적 평가 (벤치마크 점수가 이미지뿐이라 읽지 못함)
- **공식 페이지의 벤치마크는 결과 차트와 표 이미지로만 제공돼 숫자를 읽지 못했다.** 독립 평가는 찾지 못했다. Artificial Analysis 페이지는 열리지 않았다(404). [확인: 부재 / 미확인: 점수]
- **시연은 점수가 아니다.** 11시간 코딩, 3D 모델링, 영상 제작은 성공한 한 사례다. 성공률·실패 사례가 없다. [부분]
- **텍스트 전용 모델이다.** 이미지·오디오 입력을 가정하지 않는다. [확인: 페이지 서술]
- **"오픈" 표기는 아직 확인되지 않았다.** 가중치는 예고이고 날짜는 2차 서술이다. [확인/부분]
- **무료 기간 한정.** OpenRouter 무료 엔드포인트는 언제든 유료로 바뀔 수 있다. [부분]

#### 2.5 쓸 때와 쓰지 않을 때
- 쓴다: 무료 기간에 긴 컨텍스트 텍스트 작업과 코딩 보조를 비교 시험할 때.
- 쓰지 않는다: 재현이 필요한 작업, 외부 전송이 금지된 데이터, 정확도 근거가 필요한 업무. 가중치 공개 전에는 로컬에서 쓸 수 없다.
