## 2. 이 모델의 네이티브 작업 운용
Kanana 2.5의 네이티브 작업을 직접 측정한 자료는 찾지 못했다. [미확인] 아래는 이 분야와 가까운 항목의 수치다.

- 공개된 코딩 점수 없음.
- 미출시. 자체 토크나이저로 학습 비용 최대 40%, 추론 속도 최대 60% 개선(Kakao 주장).

**네이티브 작업에서 따로 확인할 것**
- 메모리 안전·동시성 버그 진단 정확도, 디버거·새니타이저 출력의 해석를 같은 과제로 비교 모델과 직접 대조한다. [추정]
