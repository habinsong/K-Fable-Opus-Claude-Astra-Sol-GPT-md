#### 2.1 위치와 사양
- Kakao가 2026-05 1분기 실적 발표에서 "공개를 준비 중"이라고 밝힌 1,500억 파라미터 LLM이다(Korea Herald 2026-05-07). 에이전트용이고 Kanana 2처럼 처음부터 직접 만들었다. 한 정리는 155B 모델이 GLM-4.5-Air 기반 모델과 일반 벤치마크에서 비슷하다고 적었다. [확인: 발표 / 부분: 155B 서술]
- Kakao 주장: 비슷한 크기 기반 모델 중 국내외 최고 성능, 계획·함수 호출에서 훨씬 큰 모델을 앞선다. 점수는 공개되지 않았다. 자체 토크나이저가 학습 비용을 최대 40%, 추론 속도를 최대 60% 개선하고 공개된 모델 중 한국어 압축률이 가장 높다고 한다. [부분, 벤더 주장]
- 용도: 카카오톡 5,000만 이용자의 개인화 AI 에이전트 서비스. 온디바이스 AI와 파트너십으로 이용자 증가에 비용이 비례하지 않게 설계했다고 한다. 출시일·가중치 공개 여부·라이선스는 없다. [확인: 서술 / 미확인]
