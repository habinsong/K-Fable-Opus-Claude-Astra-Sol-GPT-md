#### 2.1 위치와 사양
- Kakao의 오픈 가중치 MoE 계열이다. 기반(base)·지시(instruct)·추론(thinking) 세 가지가 있다. 공개는 2025-12, 갱신 2026-01-20이라는 트래커 서술이 있고 Hub 컬렉션은 "5월 20일 갱신"으로 표시됐다. 2차 보도는 2026-07에 소형 Kanana-2 두 개가 추가됐다고 한다. 날짜가 서로 맞지 않는다. [확인: 카드 / 충돌: 날짜]
- 총 30B(Hub 31B), 토큰당 활성 3B(활성 비율 10%, 계산). 48층(밀집 1), 전문가 128개(활성 6 + 공유 2), MLA 어텐션, 어휘 128,256, 컨텍스트 32,768(YaRN으로 128K까지). 언어 6개(한국어·영어·일본어·중국어·태국어·베트남어). 새 토크나이저가 한국어 토큰 효율을 30% 넘게 높였다. 카카오 이용자 데이터는 사전·후학습에 쓰지 않았다고 밝혔다. [확인]
- 라이선스는 Kanana License이고 재판매·대규모 사용에는 별도 라이선스가 필요하다는 트래커 서술이 있다(조항은 카드에 없다). [확인: 이름 / 부분: 조항]
