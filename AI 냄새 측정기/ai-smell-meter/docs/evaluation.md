# 실측 평가와 자가 개선 기록

> 2026-11-11. 이 엔진의 신호가 실제 사람 글과 AI 글에서 얼마나 걸리는지 잰 기록이다. 1차는 2022~23년 모델로, 2차는 2024~26년 모델(Claude 4.x, Gemini 2.5·3, GPT-4.1·5.2, Llama 4, Qwen3, DeepSeek 등)로 했다. 결론부터: **점수는 약한 판별기이고(AUROC 0.6~0.9), 사람 글에 '뚜렷함(35)' 이상을 주는 일은 드물다(0.1~3%). 어휘·서식 규칙은 최신 모델에서도 재현되지만, 짧고 평이한 2026년 모델 답변(60%가 0점)과 Claude의 한국어 글(AUROC 0.59)은 정규식으로 잘 안 보인다.** 연결 단절·영어 3항 나열·하이픈 줄표는 2023년 자료에서는 AI 전용 징후가 아니었고, 연결 단절은 2025년 한국어에서만 약하게 재현됐다.

## 말뭉치

모두 공개 자료이고 내려받은 글은 읽어서 통계만 냈다(실행하지 않았다). 파일은 저장소에 넣지 않았다.

| 이름 | 내용 | 규모(이번에 쓴 것) | 내려받은 곳 |
|---|---|---|---|
| KatFish | 한국어 에세이·논문 초록·시. 사람 글과 LLM 4종(GPT-4o, Solar, Qwen2, Llama3.1) | 사람 456 · AI 1,592 | GitHub `Shinwoo-Park/katfishnet`의 `katfish_dataset/*.jsonl`(8.6MB) |
| HC3 | 영어 질의응답. 사람 답변과 ChatGPT(3.5) 답변 | 사람 589 · AI 695 | Hugging Face `Hello-SimpleAI/HC3`(datasets-server rows API) |
| HC3-Chinese | 중국어 질의응답 | 사람 228 · AI 311 | 같은 곳 `Hello-SimpleAI/HC3-Chinese` |
| M4 | 다국어(영·독·러·중·아랍) 사람 글과 ChatGPT 글. 홀드아웃에는 영어의 다른 생성기(Davinci, Cohere, Dolly, Llama)도 | 개발 사람 3,267 · AI 3,168, 홀드아웃 7,305건 | GitHub `mbzuai-nlp/M4`의 `data/*.jsonl` 앞쪽 3.5MB씩 |
| 위키백과 | 사람 글 기준선(무작위 긴 문서를 1,000자 조각으로) | ko 127, en 143, fr 287, de 219, ja 106, zh 108 | 위키백과 공식 API(언어판별 무작위 문서) |

받는 방법과 합치는 방법은 `tools/build_corpus.py`와 `tools/evaluate.py`의 머리말에 있다. 홀드아웃은 개발 말뭉치와 글이 겹치지 않게(해시 대조) 새로 받은 M4의 다른 영역(위키하우, arXiv, 논문 심사평)과 다른 생성기다.

## 방법

`python3 tools/evaluate.py corpus.jsonl`이 글마다 `analyze`를 돌려 (1) 언어·장르별 점수 분포와 AUROC, (2) 규칙별 '사람 글에서 걸린 비율'과 'AI 글에서 걸린 비율'(Wilson 95% 구간), (3) 범주별 단독 AUROC를 낸다. 걸린 비율의 비(lift)가 1보다 크면 AI 글에 더 흔하다.

### 위키백과 사람 글의 언어별 오탐(늦게 받은 es·ru 포함)

AI 글이 짝지어 있지 않은 언어라 걸린 비율만 본다. 1,000자 안팎 조각마다 연결 단절이 걸린 비율과 35점 이상인 비율이다.

| 언어 | 조각 | 연결 단절 걸림 | 35점 이상 |
|---|---|---|---|
| 스페인어 | 157 | 1.3% | 0% |
| 프랑스어 | 287 | 2.1% | 0% |
| 영어 | 143 | 2.8% | 0% |
| 중국어 | 108 | 5.6% | 0% |
| 한국어 | 127 | 8.7% | 0% |
| 독일어 | 219 | 9.1% | 0% |
| 일본어 | 106 | 14.2% | 0% |
| 러시아어 | 144 | 26.4% | 0.7% |

일본어와 러시아어는 연결 단절이 사람 글의 7분의 1에서 4분의 1에 걸린다. 일본어 문장 길이 기준(28자)과 러시아어 기준(8낱말)이 짧게 잡혔을 가능성이 크고, 두 언어는 사전과 기준이 근거가 약하다. 이 신호는 점수가 아니라 편집 경고로 읽는다.

## 신호별 판정

개발 말뭉치에서 사람 글/AI 글 걸린 비율과 lift. 홀드아웃은 영어만 있다.

| 판정 | 신호 | 사람 → AI (lift) | 처리 |
|---|---|---|---|
| 재현됨 | `ko.punct.conj-comma`(접속부사 뒤 쉼표) | 0.2% → 9.5% (55) | 유지. KatFishNet이 짚은 방향과 같다 |
| 재현됨 | `any.rhythm.punct-flat`(영어 쉼표·마침표뿐) | 0.5% → 7.9% (16), 홀드아웃 0.8% → 4.2% (5.3) | 유지 |
| 재현됨 | `ko.transition.stack`, `ko.hedging.should`, `ko.rhythm.can-do`, `ko.trans.daehan`, `any.rhythm.band-lock`(ko) | lift 2.5~7.9 | 유지 |
| 재현됨 | `en.vocab.synonym-cycling` | 홀드아웃 0.9% → 2.4% (2.65) | 유지(낮은 가중치) |
| 약함 | `ko.punct.ending-comma` | 6.9% → 12.2% (1.78) | 유지(낮은 가중치) |
| **판별력 없음** | `*.cohesion.choppy-run`, `no-bridge` | 영어 6.4% → 0.6% (0.09), 중국어 0.13, 러시아어 0.11, 한국어 0.89 | 등급 C로 내리고 범주 상한 4.0 → 2.0. 편집 품질 경고로 남긴다 |
| **사람 글에 더 많음** | `any.format.em-dash`(하이픈·en dash·`--` 포함) | 영어 20%, 8%, 9% → 2%, 1%, 0% | 실제 줄표(U+2014)만 센다. 러시아어 등은 제외(정상 부호) |
| 사람 글에 더 많음 | `en.structure.triple` | 25.0% → 32.6% (1.3) | 영어는 점수에서 뺌(참고) |
| 사람 글에 더 많음 | `en.hedging.wordy`, `ko.rhythm.same-ending`, `ko.register.mixed`, `ko.format.english-gloss`, `ko.trans.plural`, `en.structure.not-only` | lift 0.04~0.67 | 점수에서 빼거나 가중치를 낮춤 |
| 규칙이 틀림 | `en.attribution.vague` | 12.2% → 13.4% (1.1) | 'historians' 같은 낱말만 있어도 걸렸다. 서술 동사가 붙을 때만 센다 |
| 검증 불가 | 영어 규칙 중 다수와 한국어 규칙 중 일부 | 전체 정규식 247개 중 89개가 말뭉치 11,000여 건에서 한 번도 안 걸림 | 2025~26년 모델의 표지가 대부분이라 이 말뭉치(2022~23년 모델)로는 확인할 수 없다 |

접속어 도배(문단의 75% 이상 문장이 접속어로 시작)는 사람·AI 글 모두 문단의 1% 안팎이다(영어 p99 0.75, 한국어 p99 0.75~0.8). AI 전용 징후가 아니므로 점수에 넣지 않고, 윤문이 접속어를 기계적으로 붙여 점수를 낮추는 꼼수를 `verify`가 알린다.

### 새로 확인된 것

- **어휘 규칙이 2024년 모델에서 재현됐다.** 1차(HC3의 2023년 ChatGPT 질의응답)에서는 약했던 어휘 규칙(interplay, underscore, foster, robust, multifaceted, pivotal, comprehensive, testament, crucial 등)이 에세이·뉴스·후기·논문 초록에서는 사람 글보다 10~50배 많이 걸렸다. 사람 글 오탐 0.1~0.6%.
- **정규식 247개 중 한 번도 안 걸리는 규칙이 89개에서 65개로 줄었다.** 남은 65개는 검증하지 못했다.
- **연결 단절은 2025년 한국어에서 약하게나마 판별력이 있었다.** 보정 후 엔진 기준으로 끊긴 단문 연속이 사람 글 7.6%, 2025년 모델 글(마크다운 없는 158편) 13.3%(lift 1.8), 문단 안 이음 부족은 5.4% 대 7.6%(1.4, 채팅 형식 2.1). 영어에서는 여전히 사람 글에 더 흔했다(lift 0.55). 그래서 **한국어만 B등급으로 되돌렸다.** 강한 증거는 아니다. 대화체가 많은 창작 답변은 엔진이 건너뛴다.
- **한국어 쉼표 신호는 2025년 모델에서도 재현됐다**(글 형식): 연결어미 뒤 쉼표 3.0% 대 9.5%(3.2), 접속부사 뒤 쉼표 0.2% 대 1.3%(6.8), 문장당 쉼표 밀도 6.7% 대 15.8%(2.4), 줄표 0% 대 5.1%.
- **영어 줄표**: 2025~26년 모델 답변에서 줄표 1개 이상이 GPT-5.2 75%, 다른 오픈 모델 33%, Claude 4.x 17%, Gemini 3 0%이고 사람 글은 1.2%다. 2개 이상이면 사람 글 0.4%라서 영어 줄표 기준을 3개에서 **2개**로 낮췄다. 1개는 약해서 세지 않는다.
- **한국어 쉼표**: 문장당 쉼표는 같은 영역끼리 견주면 2~3배 차이가 난다(에세이 사람 0.30 대 2024년 모델 0.79, 논문 초록 0.63 대 1.07). 기존 기준(2.2)은 한 번도 안 닿는 값이라 **1.0**으로 내리고 학술·문학 장르는 가중치를 줄였다. 2025년 모델 글은 사람 위키와 같은 수준(0.66)이라 쉼표만으로는 구분되지 않는다.
- **Claude의 한국어 글**은 문장이 짧고(10.6어절 대 14.6), 문장 첫머리 이음말이 적고(18% 대 32%), `-ㅂ니다` 종결이 많고(45% 대 23%), 문단을 2~3문장씩 끊는다. 단일 신호로는 0.64 이하라 합쳐서 써야 하고, 그래서 연결 단절 신호가 한국어에서는 중요하다.

### 언어별 끊긴 단문 기준 보정

### 한국어 2025년 홀드아웃

튜닝에 한 번도 쓰지 않은 Arena 한국어 응답(질문 1,300번째 이후 1,628개)을 마지막에 한 번만 쟀다. 사람 글은 개발과 같다.

| 형식 | 모델별 AUROC |
|---|---|
| 전체 | 0.855 (사람 글 35점 이상 1.1%, AI 글 15.7%) |
| 채팅 형식(마크다운 있음) | Claude 0.81, DeepSeek 0.89, Gemini 0.88, GPT 0.88, Grok 0.88, Llama 0.89, Qwen 0.91 |
| 글 형식(마크다운 없음) | Gemini 0.76, GPT 0.84, Qwen 0.75, Llama 0.64, Grok 0.66, **Claude 0.60**(62편, 35점 이상 0%) |

개발에서 본 값(Claude 글 형식 0.59, 채팅 형식 0.79)과 같은 모습이다. 한국어 개발 때 정한 기준이 홀드아웃에서도 비슷하게 동작했다. 글 형식은 표본이 작다(모델당 13~62편).


## 개선 반복 기록

1. **자가 점검(말뭉치 없이)**: 정규식 2개(`ko.hedging.rago`, `dago`)와 이메일 보호 패턴이 공백 없이 긴 글에서 제곱으로 느려졌다. 5만 자 한 줄이 40초를 넘겼다. 길이를 묶어 0.2초로 줄였고, 모든 규칙을 반복 입력으로 두들기는 시험을 더했다. 접속어를 문장마다 기계적으로 붙이면 점수가 36 → 9로 내려가면서 가짜 인과가 생기는 꼼수도 확인했다(접속어 도배 경고 추가).
2. **1차 실측 → 수정**: 위의 판정 표에서 사람 글에 많거나 판별력이 없는 신호를 내렸다. 영어 AUROC 0.678 → 0.738, 한국어 사람 글 35점 이상 2.9% → 0.3%.
3. **2차 실측 → 수정**: 사람 글에 더 많은 신호(영문 병기, `~들` 겹침, 영어 3항 나열)를 점수에서 뺐다. 영어 AUROC는 0.738 → 0.722로 조금 내렸다. 3항 나열이 약하게나마 AI 글에 많았기 때문이다(25% 대 33%). 오탐 25%를 감수하고 점수에 두는 것보다 낫다고 판단했다.
4. **홀드아웃 확인**: 튜닝에 쓰지 않은 새 영어 7,305건에서 AUROC 0.672, 사람 글 35점 이상 0.1%. 새 신호(부호 평탄, 동의어 돌려쓰기)가 재현됐다.
5. **2024~26년 모델 평가(2차)**: Arena, CringeBench, DACTYL, Beemo 등 약 3만 건으로 다시 쟀다. 바꾼 것: 한국어 끊긴 단문 기준 8 → 6어절과 언어별 기준, 한국어 연결 단절 B등급 복귀, 한국어 문장당 쉼표 기준 2.2 → 1.0(학술·문학 가중치 감소), 영어 줄표 기준 3 → 2개. 기존 말뭉치의 AUROC는 영어가 거의 그대로(0.722 → 0.719, 홀드아웃 0.672 → 0.670)이고 한국어는 0.645 → 0.672로 올랐다.
6. **자료 결함**: 네이버 뉴스 요약 자료에서 쉼표가 제거된 것을 발견해 부호 비교에서 뺐다. 그대로 썼다면 쉼표 밀도의 AUROC가 0.83으로 부풀었다(같은 영역끼리는 2~3배 차이).

## 한계

해결한 것: 최신 모델 부재(2차 평가), 임계값의 근거 없음(언어별 보정), 긴 입력 성능, 사람 글 대표성 일부(뉴스·소설·위키 추가). **해결하지 못한 것과 이유:**

- **2026년 모델의 쌍을 이룬 자료가 없다.** 사람 글과 AI 글이 짝지어진 2026년 공개 말뭉치는 찾지 못했다(2026년 4월 기준 검색). CringeBench는 AI 글뿐이고 질문이 5개로 같다. 그래서 2026년 모델은 '걸리는 규칙'과 '점수 0 비율'만 말할 수 있고 AUROC는 믿기 어렵다.
- **짧고 평이한 최신 답변은 어휘 규칙이 못 본다.** 평균 79단위의 2026년 답변은 60%가 0점이다. 정규식으로 해결할 문제가 아니고, 그래서 점수 0은 사람 글이라는 뜻이 아니다. 줄표(2개 이상)와 서식이 남은 단서다.
- **Claude의 한국어 글(마크다운 없음)은 AUROC 0.59**다. 단일 특징은 0.64 이하이고, 연결 단절·이음말 비율·종결 쏠림을 합쳐야 하는데 표본(71편)이 작아 새 점수 신호로 넣지 않았다(과적합 위험).
- **사람 글의 범위**: 위키백과, 뉴스, 소설, 학생 에세이, 논문 초록, Reddit이다. **한국어 블로그·후기·이메일(공개 자료 없음), 비원어민 영어(TOEFL11은 LDC 라이선스가 필요해 못 받음)는 없다.** 이런 글에서 오탐률은 모른다. 오탐을 줄이는 쪽으로만 기준을 잡았고(5~10%), 장르 보정(`--genre`)과 인용·점수의 한계 안내로 완화했다.
- **네이버 뉴스 자료는 쉼표가 제거**돼 있어 한국어 부호 신호 비교에서 뺐다. 한국어 사람 글의 쉼표 기준선은 에세이, 논문 초록, 위키(총 약 540편)다.
- **AI 글의 생성 조건**: 연구자가 정한 질문으로 만든 답변이다. 사용자가 문체를 지시하거나 고쳐 쓴 글은 다르게 나온다.
- 중국어·러시아어·독일어에는 AI 냄새 규칙이 없어 점수는 AI 판별이 아니다(`analyze`가 그렇게 알린다). 일본어·러시아어의 끊긴 단문 기준은 사람 글만으로 보정했다.
- 개발과 확인이 같은 자료인 부분이 있다. 한국어 2025년 홀드아웃은 개발 뒤에 새로 받은 Arena 응답으로 따로 쟀다.
